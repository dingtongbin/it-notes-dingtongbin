标准库是Python的护城河："自带电池"。这一篇精讲日常频率最高的几个模块：pathlib已在文件篇讲过，这里覆盖collections、itertools、re、datetime、logging、functools、os/sys。每个模块给最常用的那部分，够用到生产。

## collections：容器增强

### Counter：计数器

```python
from collections import Counter

words = "the quick brown fox the lazy dog the".split()
c = Counter(words)
print(c)                        # Counter({'the': 3, 'quick': 1, ...})
print(c.most_common(2))         # [('the', 3), ('quick', 1)]，前N名
print(c["the"])                 # 3；不存在的键返回0（不报错）

# 更新计数
c.update(["the", "new"])
# 算术运算
c1, c2 = Counter([1, 1, 2]), Counter([2, 3])
print(c1 + c2)                  # Counter({1: 2, 2: 2, 3: 1})
print(c1 - c2)                  # Counter({1: 2})，负数会被丢弃
```

### defaultdict：带默认值工厂的字典

```python
from collections import defaultdict

# 按首字母分组，免去"键不存在先初始化"的样板
groups = defaultdict(list)
for name in ["tom", "amy", "alice", "bob"]:
    groups[name[0]].append(name)
print(dict(groups))             # {'t': ['tom'], 'a': ['amy', 'alice'], 'b': ['bob']}

# 对比手写版（你要避免的写法）：
groups = {}
for name in ["tom", "amy"]:
    if name[0] not in groups:
        groups[name[0]] = []
    groups[name[0]].append(name)
```

defaultdict(int) 用于计数、defaultdict(list) 用于分组，这两个组合覆盖九成场景。注意：访问不存在的键会**创建**默认值（副作用），只想读不想写就用普通dict的 .get()。

### deque：双端队列

```python
from collections import deque

d = deque([1, 2, 3], maxlen=5)
d.appendleft(0)          # 左端入队O(1)——list的insert(0, x) 是O(n)
d.append(4)
print(d.popleft())       # 0，左端出队O(1)
print(d)                 # deque([1, 2, 3, 4])

# maxlen满后自动丢弃另一端元素，天然实现"最近N条"：
log_tail = deque(maxlen=100)
for i in range(1000):
    log_tail.append(i)
print(log_tail[0])       # 990，只保留最后100条
```

需要两头操作或滑动窗口（配合生成器篇的tail实现）就用deque。

### namedtuple / dataclass快速元组

```python
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p.y)          # 3 4，比p[0] 可读性强
print(p._asdict())       # {'x': 3, 'y': 4}
```

现代代码优先用dataclass（第9篇），namedtuple胜在轻量、可哈希、当元组用。

## itertools：迭代器工具箱

与生成器篇衔接：这些工具全部惰性，处理大数据流不占内存。

```python
import itertools

# islice：给迭代器切片（生成器不支持 [] 语法）
gen = (x * x for x in range(100))
print(list(itertools.islice(gen, 5, 8)))      # [25, 36, 49]

# chain：串接多个可迭代对象
print(list(itertools.chain([1, 2], "ab", (3,))))   # [1, 2, 'a', 'b', 3]

# product：笛卡尔积（嵌套循环平铺）
print(list(itertools.product([0, 1], repeat=2)))   # [(0,0),(0,1),(1,0),(1,1)]

# combinations / permutations：组合与排列
print(list(itertools.combinations("ABC", 2)))      # AB AC BC
print(list(itertools.permutations("AB", 2)))       # AB BA

# groupby：相邻分组（必须先按同一键排序！）
data = sorted([("a", 1), ("b", 5), ("a", 3)], key=lambda x: x[0])
for key, group in itertools.groupby(data, key=lambda x: x[0]):
    print(key, [g for g in group])       # a [('a',1),('a',3)]  b [('b',5)]

# count / cycle / repeat：无限迭代器
c = itertools.count(10, 2)          # 10 12 14 ...
print(list(itertools.islice(c, 3))) # [10, 12, 14]
```

groupby的"必须先排序"是最常见误用：它只对**相邻**元素分组，乱序数据先sorted。

## re：正则表达式

```python
import re

text = "联系人: tom@example.com, 备用: jerry@test.org, 电话13812345678"

# search：找第一处
m = re.search(r"[\w.]+@[\w.]+", text)
print(m.group())            # tom@example.com

# findall：找所有
print(re.findall(r"[\w.]+@[\w.]+", text))     # ['tom@example.com', 'jerry@test.org']
print(re.findall(r"1\d{10}", text))            # ['13812345678']

# 分组提取
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "发布于2026-08-30")
print(m.group(0), m.group(1), m.group(2))      # 2026-08-30 2026 08
year, month, day = m.groups()

# 替换
print(re.sub(r"\d{10,}", "***", text))         # 电话打码

# 切分
print(re.split(r"[,;、]\s*", "a, b; c、d"))     # ['a', 'b', 'c', 'd']
```

常用语法速查：

| 语法                   | 含义                              |
| ---------------------- | --------------------------------- |
| \d \w \s               | 数字 / 字母数字下划线 / 空白      |
| .                      | 任意字符（不含换行）              |
| * + ?                  | 0+ 次 / 1+ 次 / 0或1次（贪婪） |
| *? +?                  | 非贪婪版本                        |
| {m,n}                  | m到n次                         |
| [abc] [^abc]           | 字符集合 / 排除                   |
| ^ $                    | 行首 / 行尾                       |
| ( ) (?: ) (?P<name>) | 捕获组 / 不捕获组 / 命名组        |

命名组让复杂正则可读：

```python
m = re.search(r"(?P<ip>\d+\.\d+\.\d+\.\d+).*?(?P<status>\d{3})", '10.0.0.1 "GET /" 200')
print(m["ip"], m["status"])     # 10.0.0.1 200
```

三条纪律：

1. 模式一律用原始字符串r"..."，避免 \d被Python先解释。
2. 反复使用的模式先编译：pat = re.compile(r"1\d{10}")，之后pat.findall(text)，性能好。
3. 能用字符串方法（startswith/in/split）解决的别上正则——可读性优先。

## datetime：日期时间

```python
from datetime import datetime, date, time, timedelta, timezone

now = datetime.now()                    # 本地时间
print(now.year, now.month, now.day, now.hour)
print(now.strftime("%Y-%m-%d %H:%M:%S"))          # 格式化输出

# 解析字符串
dt = datetime.strptime("2026-08-30 14:30:00", "%Y-%m-%d %H:%M:%S")
print(dt.weekday())                     # 0=周一

# 加减
tomorrow = dt + timedelta(days=1)
delta = datetime.now() - dt
print(delta.days, delta.total_seconds())

# 时区：Python 3.9+ 推荐标准库zoneinfo
from zoneinfo import ZoneInfo
sh = datetime.now(ZoneInfo("Asia/Shanghai"))
utc = datetime.now(timezone.utc)
print(sh.isoformat())                   # 2026-08-30T14:30:00+08:00
print(sh.astimezone(ZoneInfo("UTC")))   # 换算到UTC

# 时间戳
ts = datetime.now().timestamp()
print(datetime.fromtimestamp(ts))
```

格式化代码速查：%Y年 %m月 %d日 %H时 %M分 %S秒 %A星期名。

工程纪律：**数据库和API一律存UTC，展示时转本地时区**。naive datetime（无时区信息）在不同机器上含义不同，是时区bug的根源。ISO 8601（isoformat()）是交换格式的事实标准。

## logging：日志print调试一时爽，生产环境必须用logging：

```python
import logging

# 一次性配置（简单场景）
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s [%(name)s] %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S",
)

log = logging.getLogger(__name__)       # 每个模块一个logger，名字用 __name__

log.debug("调试信息，默认不输出")
log.info("服务启动，监听 %s:%d", "0.0.0.0", 8000)   # 延迟格式化，别用f-string
log.warning("配置缺失，使用默认值")
log.error("请求失败")
try:
    1 / 0
except Exception:
    log.exception("预料外的错误")       # 自动附上完整栈回溯
```

输出到文件 + 控制台的进阶配置：

```python
import logging
from logging.handlers import RotatingFileHandler

log = logging.getLogger("app")
log.setLevel(logging.DEBUG)

fmt = logging.Formatter("%(asctime)s %(levelname)s %(name)s %(message)s")

fh = RotatingFileHandler("app.log", maxBytes=10_000_000, backupCount=5, encoding="utf-8")
fh.setFormatter(fmt)
log.addHandler(fh)

sh = logging.StreamHandler()
sh.setFormatter(fmt)
log.addHandler(sh)

log.info("hello")
```

RotatingFileHandler按大小轮转（10MB一份，留5份备份），TimedRotatingFileHandler按时间轮转（when="midnight"）。级别从低到高：DEBUG < INFO < WARNING < ERROR < CRITICAL，设INFO后DEBUG不输出。

## functools：函数工具

```python
import functools

# lru_cache：结果缓存（第8篇详写过，最常用）
@functools.lru_cache(maxsize=256)
def slow_query(key: str):
    ...

# partial：冻结部分参数，生成新函数（配合回调、map很顺手）
import base64
b64encode_str = functools.partial(base64.b64encode)  # 例子平淡，看下面这个
def power(base, exp): return base ** exp
square = functools.partial(power, exp=2)
print(square(9))        # 81，把exp固定为2

# reduce：折叠序列
print(functools.reduce(lambda a, b: a * b, [1, 2, 3, 4]))   # 24
```

## os / sys / subprocess

```python
import os, sys

# 环境变量（配置读取的标准方式）
os.environ.get("HOME", "/tmp")
os.environ["MODE"] = "debug"          # 只影响当前进程

# sys：解释器信息
print(sys.version)
print(sys.platform)                   # 'win32' / 'linux' / 'darwin'
print(sys.path[:3])                   # 模块搜索路径

# subprocess：执行外部命令（运维脚本必备）
import subprocess
result = subprocess.run(
    ["ping", "-n", "1", "127.0.0.1"] if sys.platform == "win32" else ["ping", "-c", "1", "127.0.0.1"],
    capture_output=True, text=True, timeout=10,
)
print(result.returncode)              # 0成功
print(result.stdout[:100])
```

subprocess纪律：参数用列表形式（不用shell=True字符串拼接，防注入）；外部命令要timeout；检查returncode而不是假设成功。
