﻿﻿﻿﻿# 元组：不可变序列

```python
point = (3, 4)
single = (42,)          # 单元素元组必须有逗号！(42) 只是括号包裹的int
empty = ()
```

元组支持索引、切片、len、in，但不支持append/remove/sort等任何修改操作。

### 元组用来干什么

**表示结构固定的记录**：坐标 (x, y)、RGB颜色 (r, g, b)、数据库行。不可变意味着安全：传出去别人改不了。

**解包赋值**（tuple unpacking）：

```python
x, y = (3, 4)
name, age, city = ("tom", 25, "beijing")

# 交换两个变量，Python特有的优雅
a, b = 1, 2
a, b = b, a

# 星号收集多余的
first, *rest = [1, 2, 3, 4]
print(first, rest)      # 1 [2, 3, 4]
*init, last = [1, 2, 3, 4]
print(init, last)       # [1, 2, 3] 4
```

**函数返回多个值**（本质就是返回元组）：

```python
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 4])
print(lo, hi)     # 1 4
```

**作为字典的键**（可变对象不能做键）。

### 元组真的不可变吗

注意一个反直觉案例：

```python
t = (1, [2, 3])
# t[0] = 99       # TypeError！
t[1].append(4)     # 合法！元组不可变指的是"元组里存的内容（引用）不变"
print(t)           # (1, [2, 3, 4])
```

元组里存的是引用，引用指向的对象如果是可变的，照样能改。元组保证的只是"槽位里的引用不变"。

## 赋值、浅拷贝、深拷贝（高频面试题）

```python
import copy

a = [1, [2, 3]]

b = a                  # 赋值：同一个对象，a is b
c = a[:]               # 浅拷贝：新建外壳，内部元素是引用
d = list(a)            # 浅拷贝，同上e = copy.copy(a)       # 浅拷贝，同上
f = copy.deepcopy(a)   # 深拷贝：外壳和内部元素全部递归复制a.append(99)           # 只影响b（同一对象）
a[1].append(88)        # 影响所有浅拷贝（内部 [2,3] 是共享的），不影响f

print(b)               # [1, [2, 3, 88], 99]
print(c)               # [1, [2, 3, 88]]
print(f)               # [1, [2, 3]]，完全独立
```

内存图景：

```
a ─┐
b ─┼─> [ref, ref]        赋值：同一个列表对象
   └──> 内部元素 [2, 3] <─┐
c ──> [ref, ref] ─────────┘   浅拷贝：外壳是新的，元素引用共享f ──> [ref, ref] ──> 新的 [2, 3]   深拷贝：全部独立
```

选择原则：

- 赋值b = a：就是想共享（最常见，性能最好）。
- 浅拷贝：元素全是不可变对象（数字、字符串）时够用。
- 元素含可变对象且要独立修改：必须deepcopy。

判断标准：改b[0]（外层槽位）和改`b[1][0]`（内层对象）分别影不影响a？影响就用deepcopy。

## 列表内存与性能

CPython的列表底层是**动态数组**：一块连续的指针数组，存的是元素的引用，不是元素本身。

- append均摊O(1)：容量不够时按约1.125倍扩容（3.12的增长因子），重新分配并拷贝。
- insert(0, x) / pop(0) 是O(n)：所有元素要挪位。需要两头操作的用collections.deque（第18篇）。
- in判断O(n)：频繁按值查找改用set/dict（O(1)）。
- 列表存100万个整数，占的内存远大于100万个int的"裸数据"——存的是指针，每个指针8字节，int对象本身另有开销。这也是numpy存在的理由。

预分配容量没有意义（不像C），直接append即可。

## 常见坑

lst = lst.sort() 得到None：sort返回None。二选一：lst.sort() 或lst = sorted(lst)。

**乘法复制可变对象**：

```python
grid = [[0] * 3] * 3      # 看似3x3全零矩阵grid[0][0] = 1
print(grid)               # [[1, 0, 0], [1, 0, 0], [1, 0, 0]]！三行是同一个列表
```

[0]*3没问题（int不可变），但 [inner]*3复制的是同一个内层列表的引用。正确：

```python
grid = [[0] * 3 for _ in range(3)]    # 每行独立
```

**遍历中增删元素**：见第1.2节，用推导式或复制后遍历。

**默认参数是可变对象**：见第2篇和第7篇。

**pop空列表 / remove不存在的值**：抛IndexError / ValueError，先if x in lst或try/except。

**元组单元素忘逗号**：(42) 是int，(42,) 才是元组。type((42)) 验证一下。
