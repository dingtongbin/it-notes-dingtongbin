﻿﻿﻿# 列表与元组

列表（list）是Python使用率最高的数据结构；元组（tuple）是它的"不可变版本"。这一篇把两个都讲透，并顺带讲清浅拷贝与深拷贝——面试和实际bug的双重高发区。

## 列表：有序可变的容器

```python
nums = [1, 2, 3, 4, 5]
mixed = [1, "hello", 3.14, True, None, [1, 2]]   # 元素类型可以混搭，还能嵌套empty = []
print(nums)
print(mixed)
```

### 增

```python
lst = [1, 2, 3]
lst.append(4)          # 尾部追加一个元素，O(1)
lst.insert(0, 0)       # 在下标0处插入0，O(n)，后面的元素全部后移lst.extend([5, 6])     # 合并另一个列表（逐个追加），O(n)
lst += [7]             # 等效extend

print(lst)             # [0, 1, 2, 3, 4, 5, 6, 7]
```

append和extend的区别：

```python
a = [1, 2]
a.append([3, 4])       # [1, 2, [3, 4]]，整体作为一个元素
b = [1, 2]
b.extend([3, 4])       # [1, 2, 3, 4]，逐个加进去
```

### 1.2删

```python
lst = [0, 1, 2, 3, 4, 5]

lst.pop()        # 弹出并返回最后一个元素，O(1)
lst.pop(0)       # 弹出下标0的元素，O(n)，后面全部前移
lst.remove(3)    # 按值删除第一个等于3的元素（找不到抛ValueError）
del lst[0]       # 按下标删除，del是语句不是方法
lst.clear()      # 清空
```

删元素的经典错误：**遍历列表的同时删除元素**。

```python
nums = [1, 2, 2, 3, 2, 4]
for n in nums:
    if n == 2:
        nums.remove(n)     # 错！边遍历边删，元素会"跳过"
print(nums)                # [1, 3, 2, 4]，有漏网之鱼
```

原因：列表按索引遍历，删除元素后后面的元素前移，索引却继续 +1，于是跳过了紧跟着的元素。

正确写法（新建列表）：

```python
nums = [1, 2, 2, 3, 2, 4]
nums = [n for n in nums if n != 2]     # 列表推导式，见下文
# 或原地修改：
nums[:] = [n for n in nums if n != 2]
```

### 改与查

```python
lst = [10, 20, 30, 20]

lst[0] = 99              # 按下标改，O(1)
print(lst.index(20))     # 1，查值返回下标，找不到抛ValueError
print(lst.count(20))     # 2，统计出现次数
print(20 in lst)         # True，成员判断，O(n)
print(len(lst))          # 4
```

### 切片（与字符串同一套语法）

```python
lst = [0, 1, 2, 3, 4, 5]
print(lst[1:4])     # [1, 2, 3]
print(lst[::-1])    # 反转
print(lst[::2])     # [0, 2, 4]

# 切片赋值：可以一次替换一段，长度都可以不同
lst[1:3] = [100, 200, 300]
print(lst)          # [0, 100, 200, 300, 3, 4, 5]

# lst[:] 是复制一份(浅拷贝)
```

### 排序与反转

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]

nums.sort()                      # 原地排序，返回None！
print(nums)                      # [1, 1, 2, 3, 4, 5, 6, 9]

nums.sort(reverse=True)          # 降序
print(sorted(nums))              # 返回新列表，不改原列表
print(sorted(nums, reverse=True))

words = ["banana", "apple", "cherry"]
print(sorted(words, key=len))    # ['apple', 'banana'... 不对，按长度排]
# 实际输出：['apple'（5）, 'banana'（6）, 'cherry'（6）] -> ['apple', 'banana', 'cherry']

# key是排序的灵魂：对每个元素调用key函数，按返回值排
students = [("tom", 90), ("jerry", 85), ("amy", 95)]
print(sorted(students, key=lambda s: s[1], reverse=True))
# [('amy', 95), ('tom', 90), ('jerry', 85)]

lst = [1, 2, 3]
lst.reverse()      # 原地反转
print(lst[::-1])   # 或切片反转，产生新列表
```

新手高频坑：lst = lst.sort() 之后lst变成None！因为sort() 原地修改并返回None。要么lst.sort()，要么lst = sorted(lst)，二选一。

## 列表推导式：Python的招牌语法

一行代码完成"遍历 + 过滤 + 变换"：

```python
# 传统写法
result = []
for n in range(10):
    if n % 2 == 0:
        result.append(n * n)
print(result)           # [0, 4, 16, 36, 64]

# 推导式，一个意思
result = [n * n for n in range(10) if n % 2 == 0]
```

语法模板：[表达式for变量in可迭代对象if条件]

```python
names = ["  tom ", "JERRY", " amy"]
cleaned = [n.strip().lower() for n in names]
print(cleaned)          # ['tom', 'jerry', 'amy']

matrix = [[1, 2, 3], [4, 5, 6]]
flat = [x for row in matrix for x in row]    # 双层循环：先外后内
print(flat)             # [1, 2, 3, 4, 5, 6]

# 三元表达式也可以放进来（if写在前面时不是过滤，是选择值）
labels = ["偶" if n % 2 == 0 else "奇" for n in range(6)]
print(labels)           # ['偶', '奇', '偶', '奇', '偶', '奇']
```

区分两种if位置：

```python
[n for n in range(10) if n % 2 == 0]         # if在后：过滤元素
["偶" if n % 2 == 0 else "奇" for n in range(6)]   # if-else在前：变换元素
```

推导式不要嵌套超过两层，否则可读性崩塌，老老实实写for循环。
