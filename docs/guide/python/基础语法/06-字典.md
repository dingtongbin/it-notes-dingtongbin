﻿﻿# 字典

字典（dict）和集合（set）都基于哈希表实现，这让它们的"按值查找"快到O(1)。这一篇讲透dict的操作和原理、set的运算，以及"为什么可变对象不能做字典的键"。

## 字典：键值对容器

```python
user = {
    "name": "tom",
    "age": 25,
    "city": "beijing",
}
empty = {}
empty2 = dict()        # 两种写法等价
```

### 增删改查

```python
user = {"name": "tom", "age": 25}

# 查：按键取值print(user["name"])        # tom，键不存在抛KeyError
print(user.get("name"))    # tom
print(user.get("email"))   # None，键不存在返回None（不报错）
print(user.get("email", "未设置"))   # 未设置，可指定默认值

# 增/改：赋值即可user["email"] = "tom@x.com"    # 新键：新增user["age"] = 26               # 已有键：修改

# 删age = user.pop("age")          # 删除并返回值，键不存在抛KeyError
user.pop("phone", None)        # 带默认值，键不存在不报错（惯用法）
del user["email"]              # del语句删除user.clear()                   # 清空
```

取值用 [] 还是 .get()：确定键一定存在用 []（缺键让它报错，尽早暴露bug）；键可能不存在且要兜底用 .get(key, default)。

### 遍历

```python
user = {"name": "tom", "age": 25, "city": "beijing"}

for key in user:                  # 默认遍历键print(key, user[key])

for value in user.values():       # 只遍历值print(value)

for key, value in user.items():   # 同时遍历键值，最常用print(key, value)
```

Python 3.7+ 保证dict按插入顺序遍历（这是语言规范，不只是实现细节）。

遍历中增删键同样会出问题（RuntimeError或逻辑错误），需要时遍历list(user.keys()) 的副本。

### 判断与合并

```python
user = {"name": "tom"}
print("name" in user)        # True，判断的是键print("tom" in user.values())

# setdefault：不存在就设置，返回（可能新设的）值counts = {}
counts.setdefault("apple", 0)
counts["apple"] += 1
print(counts)                # {'apple': 1}

# Python 3.9+ 合并运算符d1 = {"a": 1, "b": 2}
d2 = {"b": 20, "c": 3}
merged = d1 | d2             # {'a': 1, 'b': 20, 'c': 3}，d2的b覆盖d1
d1 |= d2                     # 原地合并
```

### 字典推导式

```python
nums = [1, 2, 3, 4]
squares = {n: n * n for n in nums}
print(squares)               # {1: 1, 2: 4, 3: 9, 4: 16}

names = ["tom", "jerry"]
name_len = {n: len(n) for n in names}
print(name_len)              # {'tom': 3, 'jerry': 5}

# 反转字典（值必须唯一）
m = {"a": 1, "b": 2}
print({v: k for k, v in m.items()})   # {1: 'a', 2: 'b'}
```

### 经典应用：计数

```python
text = "the quick brown fox the lazy dog the"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
print(counts)

# 更简洁的Counter（第18篇详解）
from collections import Counter
print(Counter(text.split()).most_common(2))
# [('the', 3), ('quick', 1)]
```

## dict的原理：

哈希表dict的"按键O(1) 查找"来自哈希表（hash table）：

1. 存键值对时，先对键调用hash() 算出一个整数。
2. 把这个整数对表长取模，得到存放槽位。
3. 取值时对键走同样的流程，直接定位槽位，不用逐个比较。

```
hash("name") % 8 = 3  ──>  槽位3存 ("name", "tom")
取user["name"] 时重算一遍哈希，直接到槽位3拿值
```

两个键哈希到同一槽位叫**冲突**，CPython用开放寻址法解决（探测下一个可用槽位）。表快满时自动扩容（重建更大的表并重新分布所有键）。

**由哈希机制推出的硬性规则：键必须可哈希（hashable）**

```python
d = {}
d[[1, 2]] = "x"    # TypeError: unhashable type: 'list'
d[{"a": 1}] = "x"  # TypeError
d[(1, 2)] = "x"    # 合法，元组可哈希
```

为什么list不能做键而tuple可以？因为**可变对象的内容会变，内容变了哈希值也会变，槽位就找不到了**。规则：不可变对象（int/str/tuple/frozenset）可哈希，可变对象不可哈希。这也是tuple能做键、list不能的原因。

再看一个相关反例：

```python
key = "name"
d = {key: "tom"}
key = "other"     # 改的是key变量的绑定，字典里的键字符串没变print(d)          # {'name': 'tom'}
```
