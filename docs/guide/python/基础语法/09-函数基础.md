函数是组织代码的基本单位。

## 函数基础速览

```python
def greet(name: str) -> str:     # def函数名(参数) -> 返回类型注解
    """向某人问好。"""             # docstring，紧跟def的字符串
    return f"你好，{name}"

msg = greet("tom")     # 调用
print(msg)
```

没有return（或光写return）的函数返回None：

```python
def log(msg):
    print(f"[LOG] {msg}")     # 没有return

result = log("hi")
print(result)                  # None
```

## 参数：Python最灵活的部分

### 位置参数与关键字参数

```python
def make_user(name, age, city):
    return {"name": name, "age": age, "city": city}

# 位置参数：按顺序对应
u1 = make_user("tom", 25, "beijing")

# 关键字参数：按名字对应，顺序随意，可读性好
u2 = make_user(age=25, city="beijing", name="tom")

# 混合：位置在前，关键字在后
u3 = make_user("tom", city="beijing", age=25)
# make_user(name="tom", 25)    # SyntaxError！位置参数不能在关键字参数后
```

### 默认参数

```python
def power(x, n=2):          # n有默认值
    return x ** n

print(power(3))       # 9，n用默认值
print(power(3, 3))    # 27
print(power(3, n=3))  # 同上，关键字写法更清晰
```

**默认值在函数定义时求值一次，不是每次调用时**。这句话是本篇最重要的原理，下面两种场景直接由它推导：

场景一：默认值是可变对象（经典坑）：

```python
def add_item(item, lst=[]):     # 这个 [] 在def执行那一刻创建，全函数共享lst.append(item)
    return lst

print(add_item(1))    # [1]
print(add_item(2))    # [1, 2]！两次调用共享同一个列表
print(add_item.__defaults__)   # ([1, 2],) 亲眼看看默认值被污染成什么样
```

正确写法（哨兵模式）：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

场景二：默认值用"当时的时间"之类的动态值：

```python
import datetime

def log(msg, ts=datetime.datetime.now()):   # 错：ts固定为模块加载时刻
    print(ts, msg)

def log2(msg, ts=None):                      # 对：调用时求值
    if ts is None:
        ts = datetime.datetime.now()
    print(ts, msg)
```

结论：**默认参数只能是常量（数字、字符串、None、布尔）**；需要动态值就用None占位，函数体内判断重建。

### *args：收集多余位置参数

```python
def total(*args):
    print(type(args))     # <class 'tuple'>
    return sum(args)

print(total(1, 2, 3))     # 6
print(total())            # 0
```

*args把多余的实参收进一个元组。名字可以不叫args（*nums也行），但args是惯例。

### **kwargs：收集多余关键字参数

```python
def profile(**kwargs):
    print(type(kwargs))    # <class 'dict'>
    for k, v in kwargs.items():
        print(f"{k} = {v}")

profile(name="tom", age=25)
# name = tom
# age = 25
```

### 完整参数顺序

```python
def f(pos_only, /, pos_or_kw, *args, kw_only, **kwargs):
    pass
```

- / 之前的参数只能按位置传（Python 3.8+）；
- * 之后的参数只能按关键字传；
- 中间是普通参数，两者皆可。

```python
def create_user(name, /, *, password, admin=False):
    ...

create_user("tom", password="123")       # 合法
create_user("tom", "123")                # TypeError：password必须关键字传
```

实战意义：设计API时，把语义明确的参数（如password）强制关键字传，避免调用方按位置传错。读懂别人的函数签名（比如FastAPI源码里到处是这种写法）是本节的真正目标。

### 解包传参：* 和 ** 的另一面

定义时 *args是"收集"，调用时 *iterable是"解包"：

```python
def add(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(add(*nums))          # 等价add(1, 2, 3)

info = {"a": 1, "b": 2, "c": 3}
print(add(**info))         # 等价add(a=1, b=2, c=3)

# 混合解包，常用于转发参数
def log_all(*args, **kwargs):
    print("位置参数：", args)
    print("关键字参数：", kwargs)
```

## 作用域：

LEGB规则Python找一个名字的顺序：

1. **L**ocal：函数内部2. **E**nclosing：外层函数（嵌套函数）
3. **G**lobal：模块全局4. **B**uilt-in：内置（print、len等）

```python
x = "global"

def outer():
    x = "enclosing"
    def inner():
        x = "local"
        print(x)          # local：先找到Local
    inner()

outer()

def outer2():
    x = "enclosing"
    def inner2():
        print(x)          # enclosing：Local没有，往Enclosing找inner2()

outer2()

def outer3():
    def inner3():
        print(x)          # global：Local、Enclosing都没有inner3()

outer3()
```

### 修改外层变量：

global与nonlocal关键规则：**在函数内给名字赋值，会创建局部变量**，即使外层有同名变量：

```python
count = 0

def increment():
    count = count + 1     # UnboundLocalError！右边count被视为未定义的局部变量increment()
```

原因：函数内出现赋值语句，Python编译期就把count标记为局部变量，于是右边的count在赋值完成前被读取，报错。

解决办法：

```python
count = 0

def increment():
    global count          # 声明操作的是全局变量count += 1

increment()
print(count)              # 1
```

嵌套函数改外层函数的变量用nonlocal：

```python
def counter():
    n = 0
    def inc():
        nonlocal n        # 声明操作的是外层函数的n
        n += 1
        return n
    return inc

c = counter()
print(c(), c(), c())      # 1 2 3
```

工程态度：**global尽量别用**，需要共享状态时用类、传参或返回值。global会让函数行为依赖外部状态，测试和排查都很痛苦。nonlocal在闭包/装饰器场景是正当工具（下一篇大量使用）。

### 读取外层变量不需要声明

```python
name = "tom"
def hi():
    print(name)     # 读全局变量，合法，无需任何声明
```

区分"读"和"赋值"：读按LEGB往外找；赋值默认创建局部名字。

### 可变对象作为参数：

函数能"改到"调用方的数据Python的参数传递是"传对象引用"（pass by object reference）：

```python
def modify(lst):
    lst.append(99)        # 改的是调用方那个列表对象本身
    def rebind(lst):
    lst = [1, 2, 3]       # 只是让局部名字指向新对象，不影响调用方
    a = [1, 2]
modify(a)
print(a)                  # [1, 2, 99]！被改了
b = [1, 2]
rebind(b)
print(b)                  # [1, 2]，没变
```

内存图景：

```
调用前：  a ──> [1, 2]
modify：  a ──> [1, 2, 99]      参数名lst和a指向同一对象，原地修改可见rebind：  a ──> [1, 2]          lst = [1,2,3] 让lst改指新对象，a仍指旧的lst ──> [1, 2, 3]
```

规则总结：

- 函数内**原地修改**可变参数（append/pop/修改属性），调用方看得见。
- 函数内**重新赋值**参数名，只影响局部绑定，调用方无感。
- 不想让函数修改调用方数据：传副本f(a[:]) 或函数内先拷贝。

## 函数是一等公民

函数可以像值一样赋给变量、存进列表、当参数传、当返回值返回。这是下一篇闭包/装饰器的地基：

```python
def square(x): return x * x
def cube(x): return x ** 3

ops = {"square": square, "cube": cube}     # 存字典
print(ops["square"](5))                    # 25，取出后直接调用
def apply(func, value):                    # 函数当参数return 
    func(value)

print(apply(cube, 3))                      # 27
```

map/filter/sorted(key=...) 都建立在这个特性上：

```python
nums = [3, 1, 4, 1, 5]
print(sorted(nums, key=lambda x: -x))     # [5, 4, 3, 1, 1]
print(list(map(str, nums)))                # ['3', '1', '4', '1', '5']

# lambda：匿名函数，只能写一个表达式
add = lambda a, b: a + b
print(add(1, 2))
```

lambda只适合一两行的简单逻辑；复杂逻辑定义命名函数。lambda当sorted的key、当GUI回调是主要用途。

## 类型注解（Python 3.12实用版）

```python
def process(items: list[str], limit: int = 10) -> list[str]:
    """处理条目并返回结果。

    参数:
        items: 待处理列表limit: 最多处理条数
    """
    return items[:limit]

# 3.9+ 可以直接用list[str]，旧的typing.List已不必要
# 3.10+ 联合类型用 | 写法
def parse(raw: str | bytes) -> str:
    if isinstance(raw, bytes):
        return raw.decode("utf-8")
    return raw

# 返回None的函数注解为 -> None
def setup() -> None:
    print("init")
```

注解本身不影响运行（process("abc") 照样跑到出错为止），配合mypy/pyright静态检查、IDE补全才发挥价值。现代Python项目（尤其后端）普遍全程注解，从现在起养成写注解的习惯。

## 常见坑

 **可变默认参数**：本篇核心，哨兵None写法背下来。

**UnboundLocalError**：函数内赋值即局部变量，先读后赋必炸；确实要操作全局用global（但三思）。

**修改可变参数**：modify/rebind的区别要能一眼判断；不确定就先拷贝。

**lambda里的循环变量**：

```python
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])    # [2, 2, 2]！三个lambda共享同一个i，调用时i已是2

funcs = [lambda i=i: i for i in range(3)]   # 用默认参数固定当时的值
print([f() for f in funcs])    # [0, 1, 2]
```

**返回可变对象**：函数把内部列表直接return，调用方一改，函数内部状态（如果被缓存）也被改。需要隔离就return一份拷贝。
