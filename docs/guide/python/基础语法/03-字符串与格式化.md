﻿﻿﻿﻿# 字符串与格式化

字符串是日常写代码用得最多的类型，没有之一。Python 3的str是Unicode字符串，本文覆盖：常用方法、切片、f-string、编码。

## 基本性质

```python
s1 = 'single quotes'
s2 = "double quotes"    # 单双引号等价
s3 = "it's ok"          # 内容含单引号就用双引号包
s4 = 'he said "hi"'     # 内容含双引号就用单引号包
s5 = """多行
字符串"""                # 三引号可跨行，常用于文档字符串docstring
```

不可变：所有"修改"字符串的方法都返回**新字符串**，原串不变：

```python
s = "hello"
print(s.upper())   # HELLO
print(s)           # hello，s本身没变
```

## 索引与切片

索引从0开始，负索引从 -1开始倒数：

```python
s = "python"
print(s[0])     # p
print(s[-1])    # n
print(s[-2])    # o
```

切片语法s[start:stop:step]，含头不含尾：

```python
s = "python"
print(s[0:2])    # py
print(s[:3])     # pyh... 注意是pyt，不含stop=3
print(s[3:])     # hon
print(s[:])      # python，完整复制
print(s[::-1])   # nohtyp，反转print(s[::2])    # pto，步长2
```

越界不报错（与索引不同）：

```python
print(s[:100])   # python，切片越界自动截断
# print(s[100])  # 索引越界才报IndexError
```

切片适用于所有序列（列表、元组同样语法），先在这里打牢。

## 常用方法（按使用频率）

### 查找与判断

```python
s = "2024-report.pdf"

print(s.startswith("20"))     # True，以...开头
print(s.endswith(".pdf"))     # True
print("report" in s)          # True，子串包含
print(s.find("report"))       # 5，返回起始下标，找不到返回 -1
print(s.index("report"))      # 5，找不到抛ValueError
print(s.count("t"))           # 1，子串出现次数
print("abc123".isdigit())     # False，isdigit要求全是数字print("abc".isalpha())        # True，全是字母
print(" ".isspace())          # True
print("Abc".islower())        # False
```

in运算符是最常用的判断方式，比find更直观：

```python
filename = "data.csv"
if filename.endswith(".csv"):
    print("是CSV文件")
```

### 3.2大小写与空白处理

```python
s = "  Hello World  "
print(s.strip())      # "Hello World"，去两端空白
print(s.lstrip())     # 去左端
print(s.rstrip())     # 去右端
print("  ".join)      # 顺便记住：strip() 无参数时去的是空白（空格、\t、\n）

print("hello".upper())        # HELLO
print("HELLO".lower())        # hello
print("hello world".title())  # Hello World，每个单词首字母大写print("Hello".casefold())     # 更激进的小写，用于无差别比较（德语 ß → ss）
```

strip可以指定字符集合：

```python
print("xxhelloxx".strip("x"))     # hello
print("a,b,c,".rstrip(","))       # a,b,c
```

### 拆分与合并

```python
line = "tom,25,beijing"
parts = line.split(",")       # ['tom', '25', 'beijing']
print(parts)
# 只拆一次
print("a=b=c".split("=", 1))  # ['a', 'b=c']

# 不带参数：按任意空白拆，且自动忽略连续空白
print("a   b\tc\nd".split())  # ['a', 'b', 'c', 'd']

# 合并：join是字符串方法，接收可迭代对象
print("-".join(["2024", "08", "30"]))   # 2024-08-30
print(", ".join(["a", "b", "c"]))       # a, b, c
```

split/join是一对：拆开处理再拼回来。注意join的接收者是分隔符字符串，参数是列表（或任何可迭代对象）。

```python
# 从CSV行解析字段的完整小例子row = "tom,25,beijing"
name, age, city = row.split(",")    # 配合解包（见列表篇）
print(name, age, city)              # tom 25 beijing
```

### 替换

```python
s = "2024-08-30"
print(s.replace("-", "/"))       # 2024/08/30
print(s.replace("-", "", 1))     # 202408-30，第三个参数限制替换次数

# translate用于批量字符映射，性能好
table = str.maketrans("abc", "xyz")
print("abcabc".translate(table))  # xyzxyz
```

## f-string格式化（Python 3的标准做法）

在字符串前加f，花括号里直接放表达式，这是目前最推荐的格式化方式。

```python
name, age = "tom", 25
print(f"我叫{name}，今年{age}岁")

# 花括号里是任意表达式
price = 19.5
print(f"总价：{price * 3:.2f}")       # 总价：58.50，:.2f保留两位小数
print(f"{'py'.upper()}!")            # PY!

# Python 3.12允许引号嵌套（旧版本不行）
data = {"name": "tom"}
print(f"用户：{data["name"]}")        # 3.12起合法，注意内层也用双引号
```

调试神器 = 后缀，输出"表达式名=值"：

```python
x = 42
print(f"{x=}")       # x=42
print(f"{x = }")     # x = 42（带空格的原始写法）
```

数字格式化速查：

```python
n = 1234567.891
print(f"{n:.2f}")     # 1234567.89，固定两位小数
print(f"{n:,}")       # 1,234,567.891，千分位
print(f"{n:,.2f}")    # 1,234,567.89，千分位+两位小数
print(f"{n:.2e}")     # 1.23e+06，科学计数法
print(f"{42:05d}")    # 00042，补零到5位
print(f"{0.856:.1%}") # 85.6%，百分比
print(f"{255:x}")     # ff，十六进制
print(f"{255:#x}")    # 0xff，带前缀
print(f"{7:b}")       # 111，二进制
```

对齐与填充：

```python
for name in ["tom", "jerry", "spike"]:
    print(f"{name:<10}|{name:>10}|{name:^10}")
# tom       |       tom|   tom
# jerry     |     jerry|  jerry
# spike     |     spike|  spike
# < 左对齐 > 右对齐 ^ 居中，数字是宽度
print(f"{'id':=^10}")   # ====id====，用 = 填充并居中
```

旧式 % 和str.format() 还能见到（老代码、日志），要能读懂：

```python
print("%s is %d years old" % ("tom", 25))        # % 风格print("{} is {} years old".format("tom", 25))    # format风格print("{1} before {0}".format("A", "B"))         # B before A，按序号
```

新代码一律用f-string。

## 字符串编码

计算机只认字节（0~255的数），字符要经过编码表映射成字节。

```python
s = "你好"
b = s.encode("utf-8")     # 编码：str -> bytes
print(b)                  # b'\xe4\xbd\xa0\xe5\xa5\xbd'，一个中文3字节
print(len(s), len(b))     # 2 6：字符数2，字节数6

back = b.decode("utf-8")  # 解码：bytes -> str
print(back)               # 你好
```

核心规则：

- str是字符序列（人类视角），bytes是字节序列（机器视角）。
- 读写文件、网络传输操作的都是bytes，要指定编码（几乎总是utf-8）。
- 编码解码用错编码表就会乱码或抛UnicodeDecodeError。

```python
b = "你好".encode("utf-8")
print(b.decode("gbk"))    # 娴屽ソ，乱码：用了错误的编码表解码
# print(b.decode("ascii"))  # UnicodeDecodeError
```

处理乱码文件时的套路：

```python
with open("data.txt", encoding="utf-8") as f:
    text = f.read()
# 报UnicodeDecodeError就换gbk试试（中文Windows历史遗留文件）
with open("data.txt", encoding="gbk") as f:
    text = f.read()
```

## 性能与选择

大量拼接用join，不用 +。字符串不可变，s += x在循环里每次都创建新串，复杂度O(n²)：

```python
parts = []
for i in range(10000):
    parts.append(str(i))
result = "".join(parts)     # O(n)，正确做法

s = ""; 
for i in range(10000): 
    s += str(i)   # 避免O(n²)
print(s)
```

2. **in判断子串很快**（底层是优化过的搜索算法），日常放心用。

3. **需要频繁修改的场景用列表装片段，最后join**。

## 常见坑

**strip不等于去空格**："a-b".strip("-") 去的是字符集合里的字符，不是子串。

**split的默认行为**："a  b".split(" ") 得 ['a', '', 'b']（两个空格产生空串）；"a  b".split() 得 ['a', 'b']。日志解析优先用无参split。

**join类型要求**："-".join([1, 2]) 报TypeError，元素必须是字符串，先map(str, ...) 或推导式转换。

**f-string里嵌套同引号**：Python 3.12之前f"{d["k"]}" 是语法错误，只能f"{d['k']}"。3.12放开了，但读老代码要知道这个区别。

**不可变性导致的"修改无效"**：

```python
def clean(s):
    s.strip()          # 返回值被丢弃，s没变！
    return s
print(clean("  x  "))   # "  x  "

def clean2(s):
    return s.strip()   # 正确
```

**中文标点**：代码里的引号、冒号、括号必须是英文半角。print("hello"）（中文右括号）直接语法错误，新手高频翻车点。
