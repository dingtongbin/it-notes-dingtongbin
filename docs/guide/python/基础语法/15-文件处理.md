## 基本读写

### with open：唯一正确的打开方式

```python
# 写文件（不存在创建，存在则清空）
with open("demo.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")
    f.writelines(["第三行\n", "第四行\n"])    # 接收字符串列表

# 读文件
with open("demo.txt", encoding="utf-8") as f:
    content = f.read()          # 一次读完整个文件（大文件慎用）
print(content)
```

with的作用：代码块结束（无论正常还是抛异常）自动关闭文件。不用with的话，异常发生时文件句柄泄漏，Windows下还会锁住文件导致删除失败。

模式速查：

| 模式 | 含义                            |
| ---- | ------------------------------- |
| r    | 读（默认），文件不存在报错      |
| w    | 写，清空已有内容                |
| a    | 追加，不清空                    |
| x    | 排他创建，已存在报错            |
| b    | 二进制模式，和上面组合：rb / wb |
| +    | 读写模式：r+ / w+               |

文本模式必须显式传encoding="utf-8"：Windows默认编码是gbk，跨平台必乱码。

### 按行读取：处理大文件的标准姿势

```python
# 逐行遍历（内存友好，逐行流式处理）
with open("big.log", encoding="utf-8") as f:
    for line in f:
        line = line.rstrip("\n")       # 行尾自带换行符，通常去掉
        if "ERROR" in line:
            print(line)
```

readlines() 一次性读所有行进内存（大文件爆内存），日常用for line in f。

## pathlib：现代路径操作

字符串拼路径（"dir/" + name）不可靠（Windows反斜杠、转义问题）。pathlib是标准答案：

```python
from pathlib import Path

p = Path("data") / "logs" / "app.log"    # / 拼路径，跨平台自动用对分隔符
print(p)                     # data/logs/app.log（Windows下自动是反斜杠版本）
print(p.name)                # app.log，文件名
print(p.stem)                # app，不含扩展名
print(p.suffix)              # .log，扩展名
print(p.parent)              # data/logs
print(Path.cwd())            # 当前工作目录
print(Path.home())           # 用户主目录
```

常用操作：

```python
from pathlib import Path

Path("demo.txt").exists()          # 是否存在
Path("demo.txt").is_file()         # 是文件吗
Path("data").is_dir()              # 是目录吗
Path("newdir/sub").mkdir(parents=True, exist_ok=True)   # 递归建目录（exist_ok避免已存在报错）

# 遍历目录
for f in Path(".").glob("*.py"):        # 当前目录匹配print(f)
for f in Path(".").rglob("*.py"):       # 递归所有子目录print(f)

# 读写小文件的快捷方法
Path("config.json").write_text("{}", encoding="utf-8")
text = Path("config.json").read_text(encoding="utf-8")
```

新旧对比：os.path.join("dir", "f.txt") vs Path("dir") / "f.txt"，读老代码认识即可，新代码一律pathlib。

## JSON：最通用的数据格式

### Python对象与JSON互转

```python
import json

user = {"name": "tom", "age": 25, "tags": ["admin", "vip"], "active": True}

# 序列化：Python -> JSON字符串
s = json.dumps(user, ensure_ascii=False, indent=2)
print(s)
# ensure_ascii=False：中文直接输出（默认会转成 \uXXXX）
# indent=2：美化缩进

# 反序列化：JSON字符串 -> Python对象
data = json.loads(s)
print(data["name"])
print(type(data))       # dict
```

类型对照表（必背）：

| Python     | JSON       | Python    |
| ---------- | ---------- | --------- |
| dict       | object     | dict      |
| list       | array      | list      |
| str        | string     | str       |
| int/float  | number     | int/float |
| True/False | true/false | bool      |
| None       | null       | NoneType  |

### JSON文件读写

```python
import json
from pathlib import Path

# 写
config = {"debug": False, "timeout": 30}
with open("config.json", "w", encoding="utf-8") as f:
    json.dump(config, f, ensure_ascii=False, indent=2)

# 读
with open("config.json", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded["timeout"])
```

### 解析失败与容错

```python
import json

raw = "{broken json"
try:
    data = json.loads(raw)
except json.JSONDecodeError as e:
    print(f"第 {e.lineno} 行第 {e.colno} 列解析失败: {e.msg}")
```

### 自定义类型不能直接序列化

```python
import json
from datetime import datetime

data = {"time": datetime.now()}
#json.dumps(data)   
# TypeError: Object of type datetime is not JSON serializable

# 方案一：default回调，把不认识的类型转成可序列化类型
def json_default(obj):
    if isinstance(obj, datetime):
        return obj.isoformat()
    raise TypeError(f"无法序列化 {type(obj)}")

print(json.dumps(data, default=json_default))
# {"time": "2026-08-30T10:00:00.123456"}

# 方案二：对象转dict再序列化（dataclass用dataclasses.asdict）
from dataclasses import dataclass, asdict

@dataclass
class User:
    name: str
    age: int

print(json.dumps(asdict(User("tom", 25)), ensure_ascii=False))
```

## CSV：表格数据

```python
import csv
from pathlib import Path

# 写rows = [
    ["name", "age", "city"],
    ["tom", 25, "beijing"],
    ["jerry", 22, "shanghai"],
]
with open("users.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows(rows)

# 读
with open("users.csv", encoding="utf-8") as f:
    for row in csv.reader(f):
        print(row)                # ['tom', '25', 'beijing']

# DictReader：按表头取字段，更稳
with open("users.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"], row["age"])
```

三个要点：

1. 写文件加newline=""，否则Windows下每行之间多空行。
2. Excel打开中文乱码：写文件用encoding="utf-8-sig"（带BOM，Excel认）。
3. 字段里含逗号/换行时csv模块自动加引号转义——这也是不要手写 ",".join拼文件的原因。

带类型转换的完整例子：

```python
import csv

with open("users.csv", encoding="utf-8") as f:
    users = [
        {"name": r["name"], "age": int(r["age"])}
        for r in csv.DictReader(f)
    ]
print(users)
```

## 常见坑

1. **忘了encoding="utf-8"**：Windows下默认gbk，读utf-8文件抛UnicodeDecodeError；写出去的文件到Linux又乱码。每个open都显式传。

2. **w模式清空文件**：只想追加日志用了w，历史数据全没了。追加用a。
3. **newline参数**：写csv忘了newline="" 出现双倍空行。
4. **大文件read()**：几个G的日志一次read直接OOM。逐行遍历。
5. **路径拼接用 +**："dir/" + filename在Windows下偶然能跑、Linux下反斜杠文件名出错。用pathlib。
6. **json.load和json.loads**：结尾有s处理字符串，没有s处理文件对象，记混就报AttributeError。
7. **相对路径取决于运行位置**：脚本在A目录，却在B目录运行python A/run.py，相对路径data.txt指B/data.txt。需要相对脚本定位时用Path(__file__).parent / "data.txt"。
