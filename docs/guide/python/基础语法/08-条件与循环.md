﻿﻿﻿# 条件与循环

程序 = 数据 + 流程控制。这一篇讲Python的分支与循环，重点是和C/Java不同的Python特有写法，以及容易出错的边界。

##  条件分支

### 基本形式

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:            # else if在Python里写作elif
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

规则：

- 条件后必须有冒号 :，缩进（约定4个空格）表示代码块归属。缩进是语法的一部分，不是风格问题。
- elif可以有任意多个，else最多一个且必须最后。
- 条件本身可以是任何对象（第2篇的真值测试）：if items:、if name:。

### 组合条件

```python
age, vip = 20, True
score = 85
name = "tom"
status = 200

# 逻辑运算符：and or not
if age >= 18 and vip:
    print("VIP成人用户")

# 链式比较，Python特色
if 60 <= score < 90:
    print("及格但非优秀")       # 等价于 60 <= score and score < 90

# 成员判断
if name in ("tom", "jerry"):
    print("白名单用户")

# 多值匹配用 in + 元组，比一串 or 清晰
if status in (200, 301, 302):
    print("正常状态")

```

### 三元表达式

```python
age = 20
tag = "成年" if age >= 18 else "未成年"
```

格式：值1 if条件else值2。适合简单赋值，复杂逻辑不要塞。

### match-case（Python 3.10+ 新增）

处理"按值/结构分发"的场景比if-elif链清晰：

```python
def handle(command: str):
    match command.split():
        case ["quit"]:
            return "退出"
        case ["go", direction]:
            return f"向 {direction} 走"
        case ["look", *items]:
            return f"查看 {items}"
        case _:
            return "未知命令"

print(handle("go north"))    # 向north走
print(handle("look door"))   # 查看 ['door']
```

match-case适合解析命令、消息分发。注意它做的是结构匹配，不是C的switch（switch按常量值分发，match按模式分发）。

## for循环

Python的for是"遍历迭代器"，不是C式的计数循环。

### 遍历序列

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)

# 需要下标用enumerate
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

# 并行遍历用zip
scores = [90, 85, 77]
for fruit, score in zip(fruits, scores):
    print(fruit, score)
```

### range

需要计数循环时用range：

```python
for i in range(5):          # 0 1 2 3 4，含头不含尾
    print(i, end=" ")
print()

for i in range(2, 10, 3):   # 起2止10步长3：2 5 8
    print(i, end=" ")
print()

for i in range(10, 0, -1):  # 倒序：10 9 8 ... 1
    print(i, end=" ")
print()

# range是惰性对象，不占内存；
list(range(1000000)) #才生成真列表
print(range(5))          # range(0, 5)
print(list(range(5)))    # [0, 1, 2, 3, 4]
```

### 遍历字典

```python
d = {"a": 1, "b": 2}
for key in d:                    # 默认键
    print(key, d[key])
for k, v in d.items():           # 推荐
    print(k, v)
```

### break / continue / 循环else

```python
# break：跳出整个循环
for n in range(2, 100):
    if n > 5:
        break
    print(n, end=" ")     # 2 3 4 5
print()

# continue：跳过本轮剩余语句
for n in range(10):
    if n % 2 == 0:
        continue
    print(n, end=" ")     # 1 3 5 7 9
print()

# Python特有：循环的else，循环没被break打断时执行
for n in [2, 4, 6]:
    if n % 2 == 1:
        print("发现奇数")
        break
else:
    print("全是偶数")       # 执行这行

# 没有else版本的等价代码需要借助标志变量
found_odd = False
for n in [2, 4, 6]:
    if n % 2 == 1:
        found_odd = True
        break
if not found_odd:
    print("全是偶数")
```

for...else初读陌生，但在"搜索失败"场景很干净。不用它也完全可以，知道语法即可。

### while

```python
count = 0
while count < 3:
    print(count)
    count += 1        # Python没有count++，用 += 1
```

while适合"不知道要循环几次"的场景，比如重试：

```python
import time

def do_request():
    raise ConnectionError("模拟网络失败")   # 演示用：永远失败
retries = 0
while retries < 3:
    try:
        result = do_request()      # 假设的网络请求
        break                      # 成功就跳出
    except ConnectionError:
        retries += 1
        time.sleep(1)              # 失败等1秒重试else:
    raise RuntimeError("重试3次全部失败")
```

注意死循环：while True: 必须有break或状态变化，否则程序卡死。

## 流程控制的组合实战

### 找出列表中的所有质数

```python
def is_prime(n: int) -> bool:
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):   # 只需试到平方根
        if n % i == 0:
            return False
    return True

primes = [n for n in range(2, 50) if is_prime(n)]
print(primes)    # [2, 3, 5, 7, 11, 13, ...]
```

### 菜单循环程序（终端交互的标准骨架）

```python
while True:
    print("\n1. 添加2. 查看3. 删除0. 退出")
    choice = input("请选择：").strip()

    if choice == "1":
        name = input("名称：").strip()
        print(f"已添加 {name}")
    elif choice == "2":
        print("列表内容")
    elif choice == "3":
        print("已删除")
    elif choice == "0":
        print("再见")
        break
    else:
        print("无效选项，请重新输入")
```

这个骨架记住，写任何终端小工具都是这个模式。

## 常见坑

**缩进混用Tab和空格**：Python 3直接报TabError。编辑器设置成"Tab键输入4空格"，一劳永逸。

**= 和 == 写混**：if x = 5: 在Python里直接语法错误（好事，编译期就能抓住），不像C会静默赋值。

**range含头不含尾**：range(1, 10) 不含10。要含10写range(1, 11)。

**在循环里改正在遍历的容器**：列表边遍历边删（第4篇）、字典边遍历边增删（第5篇），都会出逻辑错误或RuntimeError。

**while True里忘记状态更新**：条件永远成立且没有break，程序假死。

**浮点数做循环计数**：

```python
x = 0.0
while x != 1.0:      # 永远可能到不了！浮点误差累积
    x += 0.1
    print(x)
```

浮点计数用整数循环再换算，或用math.isclose判断。

**for循环变量泄漏**：循环结束后i依然存在且是最后一个值，不要在循环外复用它的值当"循环次数"。
