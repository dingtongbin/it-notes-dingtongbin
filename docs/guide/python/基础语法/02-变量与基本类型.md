# 变量与基本类型

Python是动态类型语言：变量没有类型，值才有类型。

## 变量：只是贴在对象上的名字

先看代码：

```python
a = 10        # 创建整数对象10，名字a指向它
b = a		  # b也指向同一个对象，没有复制
b = 20        # b改为指向新对象20，a不受影响
print(a)      # 10
print(b)      # 20
```

执行过程：

1. a = 10：Python创建整数对象10，然后把名字a绑定（bind）到这个对象上。
2. b = a：把名字b绑定到a当前指向的对象，也就是同一个10。此时没有任何复制发生。
3. b = 20：创建新对象20，把b重新绑定过去。a还指着10。

所以Python的赋值符号 =是"绑定"不是"复制"。变量是名字，对象是东西，名字通过引用指向对象。用id() 可以看到对象的身份（可以近似理解为内存地址）：

```python
a = 10
b = a
print(id(a), id(b))   # 两个id相同：a和b指向同一个对象b = 20
print(id(a), id(b))   # b的id变了，a没变
```

### 可变与不可变Python的对象分两类：

- **不可变对象（immutable）**：int、float、str、bool、tuple、frozenset。对象一旦创建，内容不能改。
- **可变对象（mutable）**：list、dict、set、自定义类的实例。内容可以原地修改。

"不可变"是什么意思？字符串拼接为例：

```python
s = "abc"
print(id(s))
s = s + "d"       # 不是把 "abc" 改成 "abcd"，而是创建新字符串对象print(id(s))      # id变了
```

而列表可以原地改：

```python
lst = [1, 2, 3]
print(id(lst))
lst.append(4)     # 原地修改，对象身份不变
print(id(lst))    # id没变
```

可变性决定了赋值行为，这是后面无数坑的根源，先看一个预览：

```python
a = [1, 2, 3]
b = a             # b和a指向同一个列表b.append(4)
print(a)          # [1, 2, 3, 4] —— a也"变"了，因为它们本来就是同一个对象
```

字符串就不会这样（不可变，任何"修改"都产生新对象）。深入讨论在列表篇和函数参数篇展开。

## 四个基本类型

### int：整数（无大小限制）

```python
x = 100
y = -50
big = 2 ** 100          # 1267650600228229401496703205376，Python整数没有溢出上限
one_million = 1_000_000 # 下划线分隔符，纯可读性print(big)
```

其他语言的int有32/64位上限，Python的int想多大就多大（受内存限制），因为它的底层是"任意精度整数"（内部用一串数字位存储）。代价是运算比固定宽度整数慢。

进制写法：

```python
print(0b1010)    # 2进制，输出10
print(0o17)      # 8进制，输出15
print(0xff)      # 16进制，输出255
```

### loat：浮点数（有精度问题）

```python
print(0.1 + 0.2)            # 0.30000000000000004
print(0.1 + 0.2 == 0.3)     # False
```

这不是Python的bug。所有遵循IEEE 754的语言（C、Java、JS全部如此）都是这个结果：浮点数用二进制存储，0.1在二进制下是无限循环小数，无法精确表示。

正确姿势：

```python
# 1. 比较用容差print(abs(0.1 + 0.2 - 0.3) < 1e-9)    # True
import math
print(math.isclose(0.1 + 0.2, 0.3))   # True，推荐

# 2. 金额等精确计算用Decimal
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3，注意用字符串初始化
```

科学计数法与无穷：

```python
print(1e6)          # 1000000.0
print(float("inf")) # 无穷大
```

### bool：布尔

只有True和False两个值（首字母大写）。bool是int的子类：

```python
print(isinstance(True, int))   # True
print(True + True)             # 2
```

**真值测试（truthiness）**：Python里任何对象都能放在if里判断，以下值视为假：

```python
False, None, 0, 0.0, "", [], {}, set(), ()
# 其余一切视为真，包括字符串 "False"、列表 [0]
```

惯用法：

```python
name = ""
if not name:            # 比if name == ""更Pythonic
    print("名字为空")

items = []
if items:               # 非空列表为真
    print("有数据")
```

### None：空值None是一个独立的类型（NoneType），全局只有一个实例。它表示"这里没有值"，不是0，不是空字符串，不是False。

```python
result = None            # 占位，稍后赋值
def find_user(uid):
    if uid == 1:
        return {"name": "tom"}
    return None          # 没找到S
user = find_user(2)
if user is None:         # 判None用is，不用 ==
    print("没找到")
```

判None必须用is：is比较对象身份（id），== 比较值。None是单例，is None又快又准确。而 == 可以被类自定义行为（__eq__），理论上一个对象可以 == None成立但不是None。

## 类型查看与转换

```python
print(type(10))            # <class 'int'>
print(type("abc"))         # <class 'str'>
print(type(1.5))           # <class 'float'>
print(type(None))          # <class 'NoneType'>
print(isinstance(10, int)) # True，推荐用isinstance判断类型
```

type和isinstance的区别：isinstance认继承关系（bool是int子类，isinstance(True, int) 为True），type严格匹配。判断类型优先isinstance。

显式转换：

```python
print(int("123"))      # 123，字符串转整数
print(int("123", 16))  # 291，按16进制解析
print(int(3.9))        # 3，注意：直接截断小数，不是四舍五入
print(round(3.5))      # 4
print(round(2.5))      # 2！银行家舍入：.5时取最近的偶数
print(float("3.14"))   # 3.14
print(str(123))        # "123"
print(bool(""))        # False
print(bool("0"))       # True！非空字符串都是真
```

转换失败会抛异常：

```python
int("abc")   # ValueError: invalid literal for int() with base 10: 'abc'
```

处理用户输入时必须考虑失败：

```python
raw = input("输入一个数字：")
try:
    n = int(raw)
    print("你输入的是", n)
except ValueError:
    print("这不是数字")
```

## 动态类型：自由与代价

```python
x = 10         # x指向int
x = "hello"    # 同一个名字，随时可以指向别的类型，合法x = [1, 2]     # 又变成list
```

名字没有类型，随时重新绑定，这叫动态类型。好处是灵活，代价是**类型错误在运行时才暴露**：

```python
def add(a, b):
    return a + b

add(1, 2)        # 3
add("a", "b")    # "ab"
add(1, "a")      # TypeError: unsupported operand type(s) for +: 'int'and 'str'
```

Python 3.12已支持类型注解（type hints），静态检查工具（mypy/pyright）能在运行前抓出这类错误，记住：注解不影响运行，是写给人和工具看的。

## 常见坑

**可变对象默认参数**（经典面试题）：

```python
def add_item(item, lst=[]):     # 错误示范：默认列表在函数定义时创建一次，所有调用共享lst.append(item)
    return lst

print(add_item(1))   # [1]
print(add_item(2))   # [1, 2] ！不是 [2]
```

正确写法：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

**== 与is混用**：判断值用 ==，判断None/单例用is。

**小整数缓存**：a = 256; b = 256; a is b为True，a = 257; b = 257在交互式里可能为False——CPython缓存了 -5~256的整数对象。永远不要用is比较数字或字符串的值。

**float精度**：金额用Decimal或以"分"为单位的整数，不要用float。

**bool("0") 是True**：非空字符串都为真，字符串 "0"/"false" 转布尔都是True。
