﻿﻿﻿# 集合：无序不重复

```python
s = {1, 2, 3}
empty = set()      # 注意：{} 是空字典不是空集合！
s2 = set([1, 2, 2, 3])     # {1, 2, 3}，自动去重
print(1 in s)          # O(1) 成员判断
s.add(4)               # 添加
s.discard(99)          # 删除，不存在不报错
s.remove(4)            # 删除，不存在抛KeyError
```

最常见用途：**去重**。

```python
ids = [101, 102, 101, 103, 102]
unique = list(set(ids))           # 顺序会乱！
unique_ordered = list(dict.fromkeys(ids))   # 保序去重（3.7+）
print(unique_ordered)             # [101, 102, 103]
```

### 集合运算

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a & b)    # {3, 4}      交集：都有的
print(a | b)    # {1, 2, 3, 4, 5, 6}  并集：合并去重
print(a - b)    # {1, 2}      差集：a有b没有
print(b - a)    # {5, 6}
print(a ^ b)    # {1, 2, 5, 6} 对称差：只属于其中一个的
print({3, 4} <= a)     # True，子集判断
print(a.isdisjoint({7, 8}))   # True，无共同元素
```

实战：两份名单的差异比对。

```python
last_week = {"tom", "jerry", "amy"}
this_week = {"jerry", "amy", "bob"}

print("新增：", this_week - last_week)     # {'bob'}
print("流失：", last_week - this_week)     # {'tom'}
print("留存：", last_week & this_week)     # {'jerry', 'amy'}
```

对比一下性能：list做x in lst是O(n)，set是O(1)。在10万元素的列表里循环做成员判断，能从秒级降到毫秒级。判断"存在性"永远优先考虑set。

### frozenset：不可变集合

```python
fs = frozenset([1, 2, 3])
# fs.add(4)    # AttributeError
d = {fs: "可哈希，能做键"}    # set不能做键，frozenset可以
```

## 遍历技巧：

enumerate与zip严格说这两个是通用迭代工具，放在字典篇一起讲因为常配合使用。

```python
# enumerate：拿到下标
names = ["tom", "jerry", "amy"]
for i, name in enumerate(names):
    print(i, name)
# 0 tom
# 1 jerry

for i, name in enumerate(names, start=1):   # 下标从1开始
    print(i, name)

# zip：并行遍历多个序列
names = ["tom", "jerry"]
scores = [90, 85]
for name, score in zip(names, scores):
    print(name, score)

# zip快速构建字典
d = dict(zip(names, scores))
print(d)        # {'tom': 90, 'jerry': 85}
```

新手常写for i in range(len(names))，Python里直接遍历元素更好；需要下标时用enumerate，需要配对时用zip。

## 常见坑

**{} 是字典不是集合**：空集合必须set()。

**KeyError的防御姿势**：

```python
config = {}
# print(config["debug"])         # KeyError
print(config.get("debug", False)) # 兜底
```

**可变对象做键**：运行时才炸，而且炸相难懂。键用str/int/tuple。

**dict.fromkeys共享可变默认值**：

```python
d = dict.fromkeys(["a", "b"], [])   # {'a': [], 'b': []}，但两个值是同一个列表！
d["a"].append(1)
print(d)             # {'a': [1], 'b': [1]}
```

**set去重丢失顺序**：要保序用dict.fromkeys()。

**遍历字典时增删键**：for k in d: d.pop(k) 会RuntimeError，改为遍历副本或收集后再删。
