# 系统托盘、菜单与快捷键

常驻型桌面工具通常要缩到托盘、提供原生菜单和快捷键。这一篇讲系统托盘怎么建、应用菜单和快捷键怎么配，以及它们和事件怎么组合成完整的交互闭环。

## 系统托盘

常驻工具的标准配置是托盘图标，点击有菜单：

```go
tray := app.NewSystemTray()
tray.SetIcon(iconBytes)
tray.SetTooltip("AceShell")

menu := app.NewMenu()
menu.Add("显示主窗口").OnClick(func(*application.ContextMenuCallbackData) {
	mainWin.Show()
})
menu.Add("退出").OnClick(func(*application.ContextMenuCallbackData) {
	app.Quit()
})
tray.SetMenu(menu)
```

托盘菜单项绑定点击回调，显示主窗口、退出这类操作直接从回调触发。

## 关闭窗口时隐藏到托盘

配合之前的 HideOnClose 思路，点 X 不退出而是收进托盘：

```go
mainWin.RegisterHook(application.WindowClose, func(e *application.WindowEvent) {
	e.Cancel()          // 拦截关闭
	mainWin.Hide()      // 改成隐藏
})
```

RegisterHook 拦截窗口事件，Cancel 掉真正的关闭，改成隐藏，达到最小化到托盘的常见效果。

## 应用菜单与快捷键

菜单可以结构化成下拉菜单，还能绑快捷键：

```go
menu := app.NewMenu()
fileMenu := menu.AddMenu("文件")
fileMenu.Add("新建连接").OnClick(func(*application.ContextMenuCallbackData) {
	app.EmitEvent("ui:new-connection", nil)   // 转发给前端处理 UI
})
fileMenu.AddShortcut("ctrl+n", ...)           // 绑定快捷键

app.SetMenu(menu)
```

菜单在 Windows/Linux 是顶部栏，macOS 是菜单栏，同一套代码渲染到各平台。

## 菜单、托盘、事件三件套

最实用的组合模式是：UI 逻辑留在前端，Go 只当事件总线：

```
菜单/托盘点击  →  Go 发事件  →  前端路由或组件响应
```

比如点菜单的"新建连接"，Go 只是 EmitEvent 一个 ui:new-connection，具体新建连接的对话框、表单全由前端处理。这样原生菜单和 Web 界面能无缝衔接，界面的统一性也更好。

## 常见坑

1. 托盘在 Linux 兼容性差：不同桌面环境（GNOME/KDE）行为不一样，要特性检测并降级。
2. 快捷键和前端冲突：系统级快捷键与页面内快捷键都要规划，避免抢。
3. 隐藏后无提示：缩进托盘后用户找不到入口，tooltip、通知要写清楚"已最小化到托盘"。
