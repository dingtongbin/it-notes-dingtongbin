# 应用入口与窗口创建

工程建好之后，逻辑从 main.go 开始。这一篇讲应用是怎么被装配起来的：创建应用实例、把前端资源嵌进二进制、创建窗口、最后把服务注册进去并启动。这是能跑通的最小闭环。

## 应用入口

核心就一个文件 main.go，用 application 包装配整个应用：

```go
package main

import (
	"embed"
	"log"

	"github.com/wailsapp/wails/v3/pkg/application"
)

//go:embed all:frontend/dist
var assets embed.FS

func main() {
	app := application.New(application.Options{
		Name:        "AceShell",
		Description: "开源桌面运维终端",
		Assets: application.AssetOptions{
			Handler: application.AssetFileServerFS(assets),
		},
		Mac: application.MacOptions{
			ApplicationShouldTerminateAfterLastWindowClosed: true,
		},
	})

	app.NewWebviewWindowWithOptions(application.WebviewWindowOptions{
		Title:     "AceShell",
		Width:     1200,
		Height:    800,
		MinWidth:  900,
		MinHeight: 600,
	})

	err := app.RegisterService(NewAppService())
	if err != nil {
		log.Fatal(err)
	}

	err = app.Run()
	if err != nil {
		log.Fatal(err)
	}
}
```

装配的顺序通常固定：创建应用、建窗口、注册服务、运行。

## 前端资源嵌入

注意到这一行：

```go
//go:embed all:frontend/dist
var assets embed.FS
```

go:embed 是 Go 标准库能力，它把整个 frontend/dist 目录编译进二进制。这是 Wails 的招牌优势的直接来源：发布物只有一个可执行文件，前端代码、静态资源全部包在里面，用户机器上不需要任何运行时。

代价是约定：打包前必须先构建前端，让 frontend/dist 存在，否则 go build 会因为 embed 找不到目录而报错。所以自动化构建流程里总是先前端后 Go。

## 创建窗口

NewWebviewWindowWithOptions 创建窗口，可以设置标题、尺寸、最小尺寸。窗口是前端 WebView 渲染的容器，前端路由都会显示在这个窗口里。

## 启动前要注册服务

RegisterService 把 Go 服务注册给框架，这样前端才能调用它绑定出来的方法。如果忘记注册，前端调用会直接失败。

## 运行与退出

最后 Run 启动应用并进入事件循环，直到窗口关闭或显式调用退出。Mac 上配置了关掉最后一个窗口就终止进程，避免后台残留。

## 常见坑

1. embed 目录不存在：先 npm run build 生成 frontend/dist，再编 Go。
2. 服务没注册：前端调方法报错，检查 RegisterService 是否执行。
3. Linux 依赖缺失：跑 wails3 task doctor 把系统包装齐再编。
