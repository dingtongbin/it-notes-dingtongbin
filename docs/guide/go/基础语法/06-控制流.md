# 控制流

Go 的控制流是"删繁就简"版：只有 for 一种循环、if 可以带初始化语句、switch 默认不穿透。这一篇把三件套讲全。

## if：可以带初始化语句

标准形式：

```go
if x > 10 {
	fmt.Println("big")
} else if x > 5 {
	fmt.Println("mid")
} else {
	fmt.Println("small")
}
```

Go 的 if 有一个 Python 没有的特性：初始化语句。常在错误处理里用，变量的作用域被限定在 if/else 内，不会泄漏到外面：

```go
if err := doSomething(); err != nil {
	return err                      // err 只在这里可见
}
// 这里访问不到 err
```

注意：条件不加括号，左花括号必须和 if 同行。

## for：唯一的循环

for 能同时替代 C 的三段式、while 和无限循环：

```go
// 三段式（同 C）
for i := 0; i < 5; i++ {
	fmt.Println(i)
}

// while 风格
n := 0
for n < 5 {
	n++
}

// 无限循环
for {
	if done() {
		break
	}
}
```

range 遍历各种集合，是使用最多的形态：

```go
for i, v := range slice {      // 切片：索引 + 值
	fmt.Println(i, v)
}
for k, v := range m {          // map：键 + 值
	fmt.Println(k, v)
}
for i, ch := range "abc" {     // 字符串：字节下标 + 字符
	fmt.Println(i, string(ch))
}
```

跳出多层循环用带标签的 break：

```go
outer:
for i := 0; i < 3; i++ {
	for j := 0; j < 3; j++ {
		if i*j > 2 {
			break outer
		}
	}
}
```

## switch：默认不穿透的分支

```go
switch day {
case "sat", "sun":              // 多值匹配
	fmt.Println("休息")
case "mon":                     // 不需要 break（自动 break）
	fmt.Println("上班")
default:
	fmt.Println("其他")
}
```

不带表达式的 switch 替代 if-else 链，更清晰：

```go
switch {
case score >= 90:
	grade = "A"
case score >= 60:
	grade = "B"
default:
	grade = "C"
}
```

需要穿透时才显式写 fallthrough：

```go
switch x {
case 1:
	fmt.Println("一")
	fallthrough
case 2:
	fmt.Println("二")     // x==1 时也执行
}
```

## 常见坑

第一个坑：for range 的值是拷贝，修改 v 不影响原数组，要改原元素用 arr[i]。

第二个坑：map 遍历顺序是随机的（Go 故意打乱），需要顺序就先收集 key 再排序。

第三个坑：nil map 可以读不能写，读 m[k] 得零值不报错，写 m[k]=v 直接 panic。
