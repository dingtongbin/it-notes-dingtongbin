# 字符串处理与格式化

strings 包是字符串处理的主场，fmt 的格式化动词是调试输出神器。这一篇补齐。前面字符串与 rune 篇讲过基础，这里进阶到包和性能。

## strings 包常用函数

```go
import "strings"

s := "Hello, Go World"

strings.Contains(s, "Go")        // true
strings.HasPrefix(s, "Hello")    // true（文件名/协议判断高频）
strings.HasSuffix(s, "World")
strings.Index(s, "Go")           // 7（不存在 -1）
strings.ToUpper(s)
strings.TrimSpace("  x  ")       // "x"（表单清洗）
strings.Split("a,b,c", ",")      // []string{"a","b","c"}
strings.Join([]string{"a","b"}, "-")   // "a-b"
strings.ReplaceAll(s, "o", "0")
strings.Fields("a  b\tc")        // 按任意空白拆（日志解析）
```

## 拼接性能

用 += 拼字符串每次分配新串，是 O(n²)。大量拼接要用 strings.Builder：

```go
// 坏：+= 每次分配新串
s := ""
for i := 0; i < 10000; i++ {
	s += "x"
}

// 好：strings.Builder
var b strings.Builder
for i := 0; i < 10000; i++ {
	b.WriteString("x")
}
result := b.String()
```

少量且可读性优先时用 fmt.Sprintf。

## 格式化动词速查

```go
fmt.Printf("%s %d %v %T\n", "x", 1, any, any)
// %s 字符串   %d 整数   %f 浮点（%.2f 两位小数）
// %v 万能默认格式（打印任意值）
// %+v 结构体带字段名（调试神器）
// %#v Go 语法表示（完整拷贝级别的打印）
// %T 类型
// %p 指针地址
// %q 带引号字符串（排查不可见字符）
// %x 十六进制（哈希/字节 dump）
```

%+v 和 %#v 是日常调试输出的最爱，比逐字段打印省事得多。

## 常见坑

第一个坑：字符串是不可变的，s[0] = 'x' 编译报错，修改要走 []byte 转换或 Builder。

第二个坑：[]byte 和 string 转换会拷贝，大字符串频繁互转有内存成本。

第三个坑：字符串字节与字符混淆，中文按 len 得到的是字节数，字符数用 len([]rune(s))。
