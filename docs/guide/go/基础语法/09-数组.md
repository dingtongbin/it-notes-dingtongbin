# 数组

数组是定长的值类型，长度写在类型里，日常几乎不用它，但理解它是理解 Slice 的前提。这一篇很短，讲清楚"数组是值类型"这个核心。

## 定义与长度是类型的一部分

```go
var a [3]int                 // [0 0 0]：长度是类型的一部分
b := [3]int{1, 2, 3}
c := [...]int{1, 2, 3}       // 自动推断长度
```

数组的长度是类型的一部分，也就是说 [3]int 和 [4]int 是两个不同的类型，不能互相赋值。

## 值类型：拷贝语义

数组赋值或传参时整体拷贝：

```go
d := b
d[0] = 99
fmt.Println(b[0])            // 1（b 没变）
```

因为拷贝语义加长度不可变，数组日常用得少，主力是可伸缩的切片。切片篇会讲它如何顶替数组的位置。
