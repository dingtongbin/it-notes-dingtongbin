# 函数

函数是 Go 错误处理的基础，原因是多返回值。这一篇讲多返回值、命名返回值、可变参数，以及函数作为一等公民的用法。

## 多返回值：错误处理的基础

Go 的惯例是返回 (结果, error)，出错时第一个值给零值：

```go
func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, fmt.Errorf("division by zero: %f / %f", a, b)
	}
	return a / b, nil
}

q, err := divide(10, 3)
if err != nil {
	log.Fatal(err)
}
fmt.Println(q)
```

只关心一个值时用下划线丢弃另一个：

```go
q, _ := divide(10, 3)      // 丢弃 error（危险，仅限明确不会出错）
```

## 命名返回值

给返回值起名字，函数体直接给它们赋值，最后裸 return：

```go
func split(sum int) (x, y int) {
	x = sum * 4 / 9
	y = sum - x
	return                   // 裸 return 返回命名的 x, y
}
```

命名返回值主要用于文档和 defer 修改返回值，复杂逻辑少用它。

## 可变参数

```go
func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}
sum(1, 2, 3)
s := []int{1, 2, 3}
sum(s...)                  // 切片展开（对标 JS 的 spread）
```

## 函数是一等公民

函数可以赋值给变量、作为参数和返回值传递：

```go
type Op func(int, int) int
func apply(a, b int, op Op) int { return op(a, b) }
result := apply(3, 4, func(a, b int) int { return a + b })
```

这是 Go 践行"组合优于继承"的基础，也和后面接口、装饰器模式的灵感有关。

## 常见坑

第一个坑：多返回值里用下划线丢弃错误，危险但允许，只在明确不会错或用测试的地方用。

第二个坑：函数参数传递值时为拷贝，改形参不影响实参；要改原值传指针。
