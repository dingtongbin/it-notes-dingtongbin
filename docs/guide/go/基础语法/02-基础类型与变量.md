# 基础类型与变量

Go 是静态强类型语言：每个变量、参数、返回值在编译期就有确定的类型。这一篇讲声明方式、类型全表、零值系统，以及和 Python 最不同的强制转换。

## 声明方式

Go 有多种声明方式，越往下越常用：

```go
var a int = 10          // 完整形式
var b = 20              // 类型推断
var c int               // 零值初始化（不是未定义！c == 0）
d := 30                 // 短声明（函数内专用，最常用）
e, f := 40, 50          // 多变量
var (                   // 分组声明（常用于包级）
	g = "x"
	h = true
)
```

零值系统是 Go 的特色，值得背下来：数字是 0、字符串是空串、布尔是 false、指针、slice、map、channel、func、interface 是 nil。变量永远有确定值，没有"未定义"这一说。

短声明 := 有两个规则。第一，至少有一个变量是新声明的，否则编译报错：

```go
x := 1
x, err := doSomething()    // 合法：x 复用，err 新声明
```

第二，未使用的变量和未导入的包都是编译错误。Go 强制你删掉死代码，这不是烦人，而是好事。

## 基础类型全表

```go
// 整数（明确宽度，没有隐式溢出）
var i8 int8 = 127          // -128~127
var u8 uint8 = 255         // 0~255（byte 是 uint8 的别名）
var i64 int64 = 1 << 62
var i int = 1 << 40        // int 宽度随平台（64 位系统=64 位）

// 浮点
var f64 float64 = 3.14159  // 默认浮点类型

// 复数（了解即可）
var c complex128 = complex(1, 2)

// 布尔（与整数不能互转）
var ok bool = true
// if 1 {}                 // 编译错：非布尔不能当条件

// 字符串（UTF-8 不可变字节序列）
var s string = "你好"
```

注意布尔没有 Python 的 truthiness：if 后面必须接布尔表达式，不能直接写 if 1。

## 显式类型转换

Go 不做隐式转换，类型转换必须显式写出来：

```go
var i int = 42
var f float64 = float64(i)     // 必须显式
var u uint8 = uint(f)
// var x float64 = i           // 编译错
```

对比 Python、JS 的宽容，Go 的类型边界极严。JS 里 "1" + 1 变成 "11"，Python 里各种宽容转换，在 Go 里全部编译报错。这种严格正是 Go 可靠性的来源。

## 常见坑

第一个坑：:= 与 = 混用导致变量遮蔽。在 if 作用域里写 x := 会声明新的 x，遮蔽外层同名变量，需要 go vet 或 linter 才能查出来。

第二个坑：跨平台代码里 int 在 32 位平台是 32 位宽，写死要明确的 int64 类型。

第三个坑：float 比较用容差或转换成整数运算，金额用分做单位，和 Python 的教训一模一样。
