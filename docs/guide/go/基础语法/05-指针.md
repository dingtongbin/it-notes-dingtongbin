# 指针

Go 有指针，但没有指针运算。指针让函数能修改调用方的值，也避免大结构体的拷贝。这一篇讲取地址、解引用、new 和 nil 指针。

## 取地址与解引用

```go
a := 10
p := &a               // p 是 *int，指向 a
fmt.Println(*p)       // 10（解引用）
*p = 20               // 通过指针修改 a
fmt.Println(a)        // 20
```

把指针传给函数，函数就能改到调用方的值，这对比值传递是个本质区别：

```go
func increment(x *int) {
	*x++              // 函数能改到调用方的值
}
increment(&a)         // a == 21
```

## new 与 nil 指针

```go
p2 := new(int)        // 指向零值 int 的指针
fmt.Println(*p2)      // 0

var p3 *int           // nil 指针
// fmt.Println(*p3)   // panic: nil pointer dereference（运行时崩溃）
```

注意 nil 指针解引用会直接崩溃，这是 Go 运行时最高频的 panic 之一，拿到指针要先判断是否为空。

## 什么时候用指针

日常开发原始类型（int、float、bool）直接值传递就够了。指针是明确的优化或语义信号，用在两处：

第一，结构体方法要修改自身时，用指针接收者。

第二，结构体很大、需要避免每次拷贝时，用指针。这个在结构体与方法篇会展开。

## 常见坑

第一个坑：直接解引用 nil 指针导致 panic，凡是拿到外部来的指针，先判断是否为空再解引用。

第二个坑：区分 *T（指针类型）和 *p（解引用）两种写法，前者是类型声明，后者是取值。
