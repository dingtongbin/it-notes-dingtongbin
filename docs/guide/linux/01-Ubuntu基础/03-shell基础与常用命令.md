# Shell基础与常用命令

这一篇解决的是"命令行到底在敲什么"的问题：shell 是什么、命令和参数的通用写法、哪些命令几乎每天都要用。读完你就具备了最基本的"在终端里安全地指挥电脑"的能力。

## shell 是什么

shell 是一个命令解释器，你把一行命令敲进去，它负责把这条命令解析出来，交给操作系统执行，再把结果打印回屏幕上。Ubuntu 默认的用户 shell 是 Bash，除它之外还有 zsh、fish 等。后面我们会频繁使用"shell 脚本"这个词，指的就是把一串命令按规则写进文件、由 shell 依次执行。

## 命令的通用结构

命令一般长这样：命令名加上空格分隔的参数，参数可以带选项（以短横线开头）：

```bash
# 命令  选项  参数
ls    -l    /home
```

选项通常是减号加一个字母，或者双减号加一个单词，例如 ls -l 和 ls --all 是混着用的。可以用 --help 或者 man 查某个命令的用法，这是自学的万能钥匙。

```bash
# 查看命令帮助
ls --help

# 查看命令手册（按 q 退出）
man ls
```

man 手册比 --help 详细得多，而且所有命令都有一套大致类似的结构，先看概要（SYNOPSIS），再看选项（OPTIONS），够解决九成问题。

## 常用基础命令

先来一组"一看就会"的：

```bash
# 列出当前目录内容
ls

# 带详细信息、按人类可读大小显示
ls -lh

# 切换到上级目录
cd ..

# 回到自己的家目录
cd ~

# 查看当前目录
pwd

# 打印一段文本（echo 后面接什么打什么）
echo "hello"
```

文件相关的基本动作：

```bash
# 创建空文件
touch notes.txt

# 新建目录（mkdir -p 会连父目录一起建）
mkdir projects
mkdir -p a/b/c

# 复制、移动、删除
cp notes.txt notes2.txt
mv notes2.txt broke.txt
rm broke.txt

# 删除目录（-r 递归，删除非空目录必备）
rm -r projects

# 查看文件类型
file notes.txt
```

rm 是危险命令，没有回收站这种东西，删了就是真删了。平时养成先 ls 看一眼、再三确认的习惯，尤其是带 -r 的递归删除。

## 通配符

shell 支持用通配符匹配一批文件，最常见的两个是星号和问号：

```bash
# 星号匹配任意多个字符
ls *.txt

# 问号匹配单个字符
ls file?.jpg
```

用好通配符就不用一条条敲文件名了。注意星号匹配的是当前目录里的文件名，不会递归进子目录，这是新手容易踩的坑。

## 小结

shell 是命令的解释器，Bash 是 Ubuntu 默认的。记住"命令 选项 参数"的结构，用 --help 和 man 自学，管理文件和目录的增删查改靠 touch、mkdir、cp、mv、rm、ls 这一组命令，配合通配符批量处理，就完整覆盖了日常的终端基本功。
