# 软件源与镜像加速

从 Ubuntu 官方源下载软件在国内常常很慢甚至超时。这一篇讲怎么换国内镜像源，把下载速度提上来，这是国内服务器的一等一省心配置。

## 软件源放在哪

软件源（repository）是 apt 获取软件包的服务器地址，配置在：

- /etc/apt/sources.list：主配置文件（22.04 及以前）
- /etc/apt/sources.list.d/：辅助目录，放额外源的配置
- /etc/apt/sources.list.d/ubuntu.sources：24.04 起默认改用的新格式（deb822）

操作前先确认自己系统用哪种格式：

```bash
cat /etc/os-release   # 看版本号
ls /etc/apt/sources.list.d/
```

## 换源的大原则

换源本质是把配置文件里的下载地址从官方换成国内镜像。三条铁律：

1. 先备份原文件，出问题能还原。
2. 版本代号要对上（22.04 是 jammy，24.04 是 noble）。
3. 换完必须 sudo apt update 刷新索引才生效。

## Ubuntu 22.04 传统格式换源

以清华 TUNA 镜像为例：

```bash
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak
sudo vim /etc/apt/sources.list
```

把内容替换成（jammy 对应 22.04）：

```
deb https://mirrors.tuna.tsinghua.edu.cn/ubuntu/ jammy main restricted universe multiverse
deb https://mirrors.tuna.tsinghua.edu.cn/ubuntu/ jammy-updates main restricted universe multiverse
deb https://mirrors.tuna.tsinghua.edu.cn/ubuntu/ jammy-backports main restricted universe multiverse
deb https://mirrors.tuna.tsinghua.edu.cn/ubuntu/ jammy-security main restricted universe multiverse
```

改完刷新：

```bash
sudo apt update
```

## Ubuntu 24.04 的 deb822 新格式

24.04 的源配置在 /etc/apt/sources.list.d/ubuntu.sources，格式更像 ini：

```bash
cat /etc/apt/sources.list.d/ubuntu.sources
```

里面是 Types、URIs、Suites、Components 等字段，把 URIs 里的官方地址换成镜像地址（如 https://mirrors.tuna.tsinghua.edu.cn/ubuntu/），Suites 保持 noble、noble-updates、noble-security 不变，然后 sudo apt update。

## 国内常用镜像源

| 镜像站 | 地址 |
|---|---|
| 清华大学 | mirrors.tuna.tsinghua.edu.cn/ubuntu |
| 阿里云 | mirrors.aliyun.com/ubuntu |
| 中科大 | mirrors.ustc.edu.cn/ubuntu |
| 腾讯云 | mirrors.cloud.tencent.com/ubuntu |

云服务器通常自带云厂商同源镜像（如阿里云 ECS 默认已是阿里云源），速度很快，不必再换。

## 验证换源是否生效

```bash
sudo apt update     # 速度明显变快、无超时报错，说明换对了
```

如果 update 报 404 或 GPG 错误，多半是版本代号写错了，回头核对代号再改。

## 小结

换镜像源的核心是：备份原配置、对准版本代号（jammy/noble）、换完 apt update。老版本改 sources.list，24.04 改 ubuntu.sources 的 URIs 字段。云厂商自带的源通常已够快。换好源，后面装什么软件都是分钟级的事。
