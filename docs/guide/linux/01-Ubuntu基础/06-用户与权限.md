# 用户与权限

Ubuntu 是多用户操作系统，安全从"谁能用这台机器、能做什么"开始。这一篇讲用户、用户组以及它们的管理命令，为下一篇文件权限打基础。

## 用户与用户组的模型

- 用户（user）：一个登录身份，有自己的家目录 /home/用户名。
- 用户组（group）：一批用户的集合，主要用于给一组用户分配共同的权限。
- root：超级用户，拥有系统一切权限。日常不用 root 直接登录，需要时用 sudo。

Ubuntu 安装时创建的第一个普通用户被自动加进 sudo 组，这正是它能 sudo 的原因。

## 查看用户与组

```bash
whoami          # 当前用户名
id              # 当前用户的 id、组 id、所属组
id 用户名       # 查看某个用户
cat /etc/passwd # 所有用户列表（一行一个）
cat /etc/group  # 所有组列表
```

/etc/passwd 每行形如 tom:x:1000:1000:,,,:/home/tom:/bin/bash，依次是：用户名、密码占位、用户ID、组ID、备注、家目录、登录Shell。x 表示密码不存这里（真正密码在 /etc/shadow）。

## 添加与删除用户

```bash
sudo adduser tom                # 创建用户（交互式设密码）
sudo useradd -m boba            # 更底层的创建，-m 自动建家目录
sudo deluser tom                # 删除用户
sudo deluser --remove-home tom  # 连同家目录一起删，慎用
```

日常管理推荐 adduser：会自动建家目录、交互式设密码、补好配置文件。useradd 偏底层，参数要自己给。

## 管理用户组

```bash
sudo groupadd devs         # 新建组
sudo usermod -aG devs tom  # 把 tom 追加到 devs 组（-a 追加不覆盖）
groups tom                 # 查看 tom 属于哪些组
sudo groupdel devs         # 删除组
```

注意 usermod 加组用 -aG，只写 -G 会把用户原有的组覆盖掉，新手很容易踩这个坑把 sudo 丢了。

## 临时提升权限：sudo

```bash
sudo apt update           # 以 root 身份执行
sudo -i                   # 切换到 root 的登录 Shell
sudo -u www-data ls       # 以 www-data 身份执行单条命令
```

sudo 默认要求验证当前用户密码，结果有缓存（几分钟内不再重复问）。管理 sudo 权限的文件是 /etc/sudoers，紧急时用 visudo 编辑（会有语法检查，防改坏）。

## 切换用户

```bash
su - tom      # 切换到 tom（需要 tom 密码）
su -          # 切换到 root（需要 root 密码）
```

su 和 sudo 的区别：su 是完整切换身份（需要目标用户密码），sudo 是以 root 临时执行单条命令（只需自己密码）。服务器日常用 sudo 即可，su 较少。

## 修改密码

```bash
passwd                # 改当前用户密码
sudo passwd tom       # 管理员改 tom 的密码
```

## 小结

用户是多用户系统的身份，组用来批量分配权限，root 是最高权限不建议日常登录。创建用户用 adduser，加组用 usermod -aG（别丢 sudo），临时提权用 sudo，切换身份用 su。把"我是谁"搞清楚，下一篇的文件权限才有基石。
