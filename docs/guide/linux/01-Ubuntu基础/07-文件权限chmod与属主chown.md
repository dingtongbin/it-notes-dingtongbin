# 文件权限chmod与属主chown

理解了用户与组，这一篇把权限落到文件和目录上：看懂 ls -l 那一串权限位、用 chmod 修改访问权限、用 chown 改属主。权限是 Ubuntu 安全防护的第一道闸门。

## 读取权限位

ls -l 的第一列长这样：

```
-rw-r--r-- 1 tom devs 1234 Jan 1 12:00 file.txt
```

拆开看：

| 位置 | 含义 | 例子 |
|---|---|---|
| 第1位 | 文件类型 | - 普通文件、d 目录、l 链接 |
| 2-4位 | 属主(owner)权限 | rw- |
| 5-7位 | 属组(group)权限 | r-- |
| 8-10位 | 其他用户(other)权限 | r-- |

后面依次是：硬链接数、属主、属组、大小、修改时间、文件名。

## rwx 分别是什么

| 权限 | 对文件 | 对目录 |
|---|---|---|
| r 读 | 查看内容 | 列出目录内容（ls） |
| w 写 | 修改内容 | 增删目录里的文件（建、删、改名） |
| x 执行 | 作为程序运行 | 进入目录（cd） |

注意 rwx 对文件和目录语义不同，这是新手最容易混的点。对目录有 r 没 x，能 ls 出名字却进不去；有 x 没 r，能进却列不出来。目录要"能看能进"需要 r 和 x 都给。

## 用 chmod 修改权限

chmod 有两种写法：符号法和数字法。

### 符号法

```bash
chmod u+x script.sh     # 给属主加执行位
chmod g-w file.txt      # 去掉属组写权限
chmod o=r file.txt      # 其他人设为只读
chmod a+r file.txt      # 所有人加读
```

u 表属主，g 属组，o 其他，a 所有人。+ 加，- 减，= 设为。

### 数字法

把 rwx 用数字表示：r=4，w=2，x=1，相加得一位。rwx 就是 7，r-x 是 5，r-- 是 4。

```bash
chmod 755 script.sh    # 属主 rwx，组/其他 r-x
chmod 644 file.txt     # 属主 rw-，组/其他 r--
chmod 600 secret.key   # 仅属主可读写，密钥类用它
```

数字法更常用，一行指定全部三个角色。记住 755（程序/目录）、644（普通文件）、600（密钥）这三个默认值就够日常用了。

## 递归修改权限

改整个目录树用 -R：

```bash
chmod -R 755 /opt/myapp
```

递归改权限要小心，一刀切容易把本来该 600 的文件也放开，能精准就别 -R。

## 改属主与属组：chown

```bash
sudo chown tom file.txt            # 改属主为 tom
sudo chown tom:devs file.txt       # 同时改属主和属组
sudo chown :devs file.txt          # 只改属组
sudo chown -R tom:devs /opt/myapp  # 递归改整个目录树
```

chown 需要 root 权限（用 sudo）。改属主常在部署应用后执行，让服务运行的用户能访问它的目录。

## 常见权限问题的排查思路

服务报权限拒绝（Permission denied），按这个顺序查：

```bash
ls -l 文件           # 属主属组对不对
ls -ld 目录          # 目录本身的权限（cd 需要执行位）
id 运行服务的用户    # 确认用户属于哪些组
```

Web 服务常见做法：文件 644、目录 755、目录属主改成服务账号。绝对不要图省事用 777（全世界可写，是安全大洞）。

## 小结

ls -l 第一列拆开是"类型+属主+属组+其他"九位权限。对文件 r 读 w 写 x 执行，对目录 r 列 w 增删 x 进入。改权限用 chmod（数字法 755/644/600 最常用），改属主用 chown（要 sudo，递归用 -R）。权限问题的排查先看属主属组，再看目录本身权限，别用 777 兜底。
