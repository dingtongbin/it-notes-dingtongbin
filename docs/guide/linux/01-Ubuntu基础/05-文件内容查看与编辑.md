# 文件内容查看与编辑

管理 Ubuntu 时天天要和文件内容打交道：看配置、翻日志、对比差异、临时改文件。这一篇讲查看文件的高效命令（cat、less、tail、head、grep），以及命令行编辑文件的基本功。

## 查看整个文件

```bash
cat /etc/hostname
nl /etc/hostname
```

cat 一次打印全部内容，nl 在此基础上加行号。cat 适合看小文件和一次性读完，大文件或日志别用 cat，会刷屏。

## 大文件分段看：less

less 是查看大文件的神器，滚动、搜索都不吃内存：

```bash
less /var/log/syslog
```

进入 less 后常用操作：
- 空格：下一页，b：上一页
- 方向键：一行行滚动
- 斜杠加关键词：向下搜索，按 n 跳到下一个
- q：退出

less 不会把整个文件一次性读进内存，读日志和长配置文件时优先用它。

## 只看头尾：head 与 tail

```bash
head -5 file.txt
tail -5 file.txt
tail -n 20 file.txt
```

tail 有个杀手锏 -f，实时跟踪文件增长，看日志必备：

```bash
tail -f /var/log/syslog
tail -f -n 50 app.log
```

调试服务、观察日志时 tail -f 是你最好的朋友，按 Ctrl+C 停止。

## 按内容搜索：grep

grep 在文本里按行匹配关键词，输出命中的行：

```bash
grep root /etc/passwd            # 找含 root 的行
grep -i error app.log            # 忽略大小写
grep -n foo config.conf          # 带行号
grep -c error app.log            # 只输匹配行数
grep -r version /etc/nginx/      # 递归搜索目录
grep -v "^#" nginx.conf          # 反选，去掉注释行
```

grep 配合管道威力巨大：ps aux 管道 grep 进程名 基本天天用。加 -v 去掉干扰，加 -r 递归目录，-c 数匹配行数。

## 用 vim 编辑文件

查看用 tail/less 就够，要修改文件则需要编辑器。vim 是服务器上最常预装也最难上手的编辑器，会了收益极大：

```bash
vim /etc/nginx/nginx.conf
```

vim 有模式概念，新手最大的坎在于模式切换：

| 模式 | 作用 | 进入方式 |
|---|---|---|
| 普通模式 | 移动光标、删除、复制 | 打开即在此，按 Esc 回来 |
| 插入模式 | 打字输入内容 | 按 i |
| 命令行模式 | 保存、退出、搜索 | 按英文冒号 |

最基础操作闭环：按 i 进入插入、打字、按 Esc 回普通模式、按冒号进入命令模式、输 wq 回车保存退出。

- 保存退出：w 保存、q 退出、q! 不保存强退、wq 保存并退出
- 普通模式下 dd 删一行、yy 复制一行、p 粘贴

不想用 vim 的话，nano 更简单：nano 文件名 打开，Ctrl+O 保存，Ctrl+X 退出。

## 小结

查看小文件用 cat、大文件用 less，看头尾用 head/tail（tail -f 实时跟日志），搜索用 grep。修改文件用 vim（记住 i 插入、Esc 回普通、wq 保存）或更友好的 nano。会看会改，配置文件就不再是拦路虎了。
