# 使用命令行终端

这一篇解决的是新手最常见的困惑：怎么打开终端、终端里的提示符是什么意思、怎么安全地退出终端、以及为什么很多命令前面要加 sudo。掌握了这些，后续所有命令行操作才有立足点。

## 打开一个终端

在 Ubuntu 桌面环境下，快捷键 Ctrl+Alt+T 可以直接打开一个新的终端窗口。如果你用的是终端模拟器，它本质就是一个运行 shell 的窗口，常见的默认 shell 是 Bash。

```bash
# 打开终端后，默认会显示类似这样的提示符
# 当前用户名@主机名:当前目录$
# 例如 user@myhost:~$
```

提示符末尾的符号有意义：普通用户显示美元符号，超级用户（root）显示井号。看到井号就说明你当前以 root 身份在执行命令，操作要格外小心。

## 常见终端操作

```bash
# 查看当前目录（Print Working Directory）
pwd

# 清屏
clear

# 查看用户名和主机名
whoami
hostname
```

Tab 补全是命令行效率的基石之一，目录名、文件名、命令名都可以补全；连续按两次 Tab 会列出所有可能的补全项。

## sudo 是什么

sudo 用于以超级用户权限执行单条命令。日常管理软件包、修改系统配置都需要它，因为普通用户没有权限去动系统目录（如 /etc、/var 下的内容）。

```bash
# 以 root 权限更新软件包索引
sudo apt update
```

需要注意：sudo 输入的密码是你自己用户的登录密码，而不是 root 的密码。Ubuntu 默认不启用 root 账户，而是用 sudo 授权，这是一条重要的安全设计，可以避免长期以最高权限操作而导致误删系统文件。

## 退出终端

```bash
# 退出当前 shell / 关闭终端
exit
```

在远程 SSH 会话中，exit 的作用是断开连接，回到本地提示符。终端关闭后，前台运行的程序通常也会随之终止，这就是后面讲进程管理时为什么需要后台运行和 nohup 的铺垫。

## 小结

终端等于一个运行 shell 的窗口，Ctrl+Alt+T 打开，Tab 补全提效，pwd 定位当前目录，普通用户提示符是美元符号、root 是井号，需要管理员权限的单条命令用 sudo 前缀，退出用 exit。把这几件事记牢，命令行就不会让人望而生畏了。
