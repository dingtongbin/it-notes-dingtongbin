# 文件与目录管理

这一篇解决的是对文件和目录做增删查改、移动复制、看懂 ls 长格式输出的问题。这是使用率最高的一批命令，把所有选项讲透一点后面会很省心。

## 目录结构速记

Linux 目录结构遵循 FHS（文件系统层级标准），常用到的就几个：

| 路径 | 用途 |
|---|---|
| / | 根目录，一切挂载点的起点 |
| /home | 普通用户的家目录，每个用户一个子目录 |
| /root | root 用户的家目录 |
| /etc | 系统与应用的配置文件 |
| /var | 变动数据，如日志、缓存、临时文件 |
| /tmp | 临时文件目录，重启会清空 |
| /usr | 安装的软件和共享资源 |
| /opt | 第三方手动安装的大型软件 |

绝对路径以斜杠开头，例如 /etc/nginx；相对路径不以此开头，例如 ../docs，相对当前目录计算。

## 列出文件：ls

```bash
# 基础列出
ls

# 详细模式，含权限、属主、大小、时间
ls -l

# 显示所有文件（含以点开头的隐藏文件）
ls -a

# 人类可读大小 + 详细 + 全部
ls -lah

# 按时间或反向排序
ls -lt
ls -lr
```

ls -l 的第一列形如 -rw-r--r--，它包含了类型和权限信息，这一串在下一篇 chmod 会重点展开。第一字符是 - 表示普通文件，d 表示目录，l 表示符号链接。

## 创建与复制移动

```bash
# 创建目录
mkdir myapp
mkdir -p /tmp/a/b/c        # -p 递归创建父目录

# 复制文件或目录
cp notes.txt notes2.txt
cp -r srcdir dstdir        # 复制目录必须加 -r
cp -a old new              # 保留全部属性（含软链接、权限）的完整复制

# 移动或重命名
mv old.txt new.txt         # 重命名
mv file.txt /tmp/          # 移动到别的目录
```

mv 在同一文件系统内是"改名字"级别的廉价操作，跨文件系统才会真的搬数据。移动或复制到目标位置时，若目标已存在同名文件，后者会直接覆盖前者，且系统不会提示。

## 删除：rm

```bash
rm file.txt                # 删文件
rm -r dirname              # 递归删目录
rm -rf dirname             # 递归强制删除（危险）
rm -i *.log                # 逐个询问确认
```

rm 没有回收站，删了就没了，-rf 组合尤其要三思。想找回很难，所以在批量删除前先 ls 或者用 find 列一遍要删的东西。

## 链接：ln

链接分硬链接和软链接（符号链接），软链接更常用——它就是 Windows 里的快捷方式。

```bash
# 创建软链接：ln -s 目标 链接名
ln -s /etc/nginx/nginx.conf /home/user/nginx-link.conf

# 查看链接指向
ls -l /home/user/nginx-link.conf
```

软链接可以跨文件系统、可以指向目录，删除指向目标不影响链接文件本身。硬链接则只能在同一文件系统内指向文件，不常用，遇到认识即可。

## 查看目录容量

```bash
# 各文件/目录占用大小
du -sh /home/user

# 当前目录下每个子目录的大小
du -sh */

# 查看磁盘整体占用
df -h
```

du 统计的是占用，df 统计的是一整个分区/挂载点的使用情况，排查"磁盘满了"时两个都会用到。

## 小结

文件与目录管理就是 ls、mkdir、cp、mv、rm、ln、du 这一组命令的特权搜索循环。看懂 ls -l 输出含义、记牢 rm 没有回收站、用好 -p 递归建目录和 -r 复制目录这几个关键选项，Linux 下的文件操作就基本过关了。
