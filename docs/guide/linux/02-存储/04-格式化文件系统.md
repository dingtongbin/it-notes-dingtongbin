# 格式化文件系统

分好区之后，分区还只是一片裸空间，要给它建立文件系统才能存文件。这一篇讲 mkfs 系列命令：怎么格式化、格式化前后要确认什么、常用参数怎么选。

## 格式化做什么

格式化（make filesystem）就是在分区上写入文件系统的元数据结构：超级块、inode 表、块位图等。完成后操作系统才能在这个分区上创建目录和文件。命令家族叫 mkfs.*。

## 格式化前的确认

格式化会清空目标上的全部数据，动手前必须确认两件事：

```bash
lsblk -f        # 看每个分区当前的文件系统和挂载状态
df -h           # 确认它没被挂载使用
```

铁律：
1. 确认设备名没敲错（/dev/sdb1 和 /dev/sda1 一字之差就是灾难）。
2. 目标分区必须处于未挂载状态，正在挂载的分区格式化会被拒绝。

## 格式化为 ext4

ext4 是 Ubuntu 的默认文件系统，稳、工具链全：

```bash
sudo mkfs.ext4 /dev/sdb1
```

常用变体：

```bash
sudo mkfs.ext4 -L data /dev/sdb1    # -L 给卷标，方便识别
sudo mkfs.ext4 -m 1 /dev/sdb1       # 预留 1% 给 root（默认 5%，数据盘可调低）
```

## 格式化为 xfs

xfs 在大文件、高并发写入场景表现出色，数据库常用：

```bash
sudo apt install xfsprogs    # xfs 工具默认可能没装
sudo mkfs.xfs /dev/sdb1
sudo mkfs.xfs -L data /dev/sdb1
```

注意 xfs 不能缩容，只扩不缩，规划空间时要有数。

## 格式化为 btrfs

btrfs 支持快照、压缩、校验等现代特性：

```bash
sudo mkfs.btrfs /dev/sdb1
sudo mkfs.btrfs -L data /dev/sdb1
```

## 验证格式化结果

```bash
lsblk -f
```

输出里 FSTYPE 列应该显示对应的文件系统类型，LABEL 列显示卷标。看到了就说明格式化成功，下一步就可以挂载了。

## 给分区换个类型会怎样

在一个已是 ext4 的分区上再跑 mkfs.xfs，等于推倒重建，原数据全没。文件系统之间不能"转换"，只能重新格式化。所以重要数据先备份，再动 mkfs。

## 常见坑

1. 格式化了错误的盘：lsblk 确认再敲命令，用完整路径别用缩写。
2. 对挂载中的分区格式化：先 umount。
3. 忘了 xfs 工具没装：apt install xfsprogs。
4. 误以为格式化能"修复"坏盘：物理坏道要换盘，格式化救不了。

## 小结

格式化用 mkfs.ext4 / mkfs.xfs / mkfs.btrfs，-L 打卷标。动手前用 lsblk -f 确认设备名和挂载状态，格式化即清空数据、不可逆、不能转换只能重建。ext4 稳妥默认，xfs 大文件强但不可缩容，btrfs 特性多。格式化完 lsblk -f 验证，接下来就是挂载使用。
