# 磁盘识别与分区

接一块新盘到机器上，运维的下一步一定是把它识别出来并划分成分区。这篇文档解决"这块盘叫什么、怎么分、分表用 MBR 还是 GPT"三个问题，命令覆盖 lsblk、fdisk、parted、gdisk，最后给出对照表帮你选对分区表类型。

## 新盘识别三步走

插上磁盘后先确认内核看到了它：

```bash
lsblk
```

```bash
dmesg | tail -20
```

lsblk 看设备是否出现在列表里；dmesg 看内核日志里有没有认盘报错，比如 no media、unrecognized disk 之类。两者都没问题，再确认盘是否已有分区表格式（part label）：

```bash
lsblk -o NAME,SIZE,TYPE,FSTYPE,PARTLABEL
```

如果这块盘下面还没有任何子设备，PARTTYPE 为空，说明它是一块干净的裸盘，下一步就是分区。

## 分区表：MBR 与 GPT

分区表是写在磁盘头部、用来描述"这块盘被切成几块、每块在哪"的元数据。目前只有两种主流格式。

| 特性 | MBR | GPT |
| --- | --- | --- |
| 最大磁盘 | 2TB（受扇区地址限制） | 可到 8ZB 以上 |
| 分区数量 | 最多 4 个主分区 | 默认 128 个 |
| 备份 | 无（坏了难救） | 磁盘头尾各存一份 |
| 引导兼容 | BIOS 传统引导友好 | 支持 UEFI |
| 适用 | 老机器、小盘、兼容性优先 | 现代默认选择 |

生产经验的结论很直接：只要磁盘大于 2TB，或者不在刻意模拟老 BIOS 的场景里，一律选 GPT。大小写注意，工具里区分大小写的指令很多，gdisk 里是 o 来新建 GPT 表，fdisk 里新建 GPT 也是 o。

## 用 fdisk 快速分区（MBR/GPT 通用）

fdisk 交互界面适合小规模手工操作。以 /dev/sdb 为例：

```bash
sudo fdisk /dev/sdb
```

交互里的关键指令（字母小写）：

```bash
# 查看当前分区与磁盘信息
p
# 新建 GPT 分区表（旧盘切换格式，会清空全盘）
g
# 新建分区
n
# 写盘并退出（必须执行 w 才算落盘）
w
```

新建时 fdisk 会问分区号、起始扇区、结束扇区。默认值会沿用磁盘头和上一段边界，一般直接回车即可；要留出整块盘就回车到结束。注意：只有执行 w 之后改动才写盘，中途按 q 会放弃本次操作。

## 用 parted 建 GPT 分区（面向大容量）

parted 适合脚本化和处理超过 2TB 的大盘，GPT 是其默认分区格式。非交互式用法：

```bash
sudo parted /dev/sdb mklabel gpt
```

```bash
sudo parted -s /dev/sdb mkpart primary 0% 100%
```

第一行建 GPT 表，第二行把整块盘划成一个分区（从 0% 到 100%）。parted 里分区的编号是 1，结果会生成 sdb1。

创建完分区后要通知内核重读分区表，尤其新盘中常遇"刚建完分区 lsblk 看不到"的初始化延迟：

```bash
sudo partprobe /dev/sdb
```

```bash
sudo udevadm settle
```

## 用 gdisk 处理 GPT 高级场景

如果分区分到一半发现要调整类型码，gdisk 是 GPT 的瑞士军刀。它支持传统分区 GUID 与文件系统类型码的映射，能改分区类型、恢复主表、改名称。常用交互同 fdisk 相近，但分区类型设置用 t：

```bash
sudo gdisk /dev/sdb
```

```bash
# 修改某个分区的类型码
t
```

gdisk 对新手略重，日常场景 fdisk 的 g + n + w 三步足以覆盖九成需求，gdisk 更多用于那些"分区类型码要对上特定文件系统或用途"的细致场景。

## 分区表常见报错与落盘校验

- 认不到整盘 2TB 以上空间 → 大概率在用 MBR，改用 GPT 重建分区表。
- partprobe 后仍无分区 → 先 udevadm settle 等待，再确认分区编号是否正确。
- 覆盖系统盘 → 强烈建议先 lsblk 确认目标，再加硬盘盘符创建到最后，防止误毁已有数据。

每次分区落盘后用同一命令复查是低成本好习惯：

```bash
lsblk /dev/sdb
```

看到新的 sdb1 且 PARTTYPE 有值，就说明分区表建好，可以进入格式化步骤。

## 小结

识别磁盘用 lsblk 加 dmesg，分区表优先选 GPT，超过 2TB 尤其如此。手工小规模用 fdisk（g、n、w 三步），大容量或脚本化用 parted，需要精细调整 GUID 类型码用 gdisk。任何分区操作都以 lsblk 复查收尾，写盘前先确认目标盘号，这是避免误操作的第一道防线。
